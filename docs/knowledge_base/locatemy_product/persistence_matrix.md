# 数据保留与账号归属

2026-09-17 用户确认的产品边界；本表描述目标行为，不声明当前实现已完成。账号业务记录只在线读写 Supabase，不保留离线创建、自动同步或照片待上传队列。

| 内容 | 权威保存位置 | 重启后 | 退出后 | 关键边界 |
| --- | --- | --- | --- | --- |
| 基础登录状态 | Supabase Auth SDK | SDK 默认保持登录 | 结束当前设备登录 | 不自建远端重复核验、失效计时和清理协调流程 |
| 语言与简单界面设置 | 本机 KV | 保留 | 保留 | 不绑定账号；切换语言覆盖正常与失败状态 |
| 当前选点、A/B、页面栈及未提交表单 | 页面／进程内存 | 无跨重启恢复承诺 | 按普通页面生命周期结束 | 无清理证明或持久化屏障；地图往返不丢当前表单 |
| 首页及公共分析缓存 | 本机 SQLite | 按缓存规则保留 | 保留 | 不可用不冒充零 |
| 收藏地点 | Supabase 账户记录 | 登录后在线读取 | 云端保留 | 在线新增、读取、选择和删除；不保留私有 SQLite 缓存／离线创建队列 |
| 预算预案及当前选择 | Supabase 账户记录 | 登录后在线读取 | 云端保留 | 支持新增、编辑、重命名、选择和删除；当前选择至多一份 |
| 隐患报告及投票 | Supabase | 在线读取 | 云端保留 | 公开报告可读，作者管理自己的状态／删除，每账户每报告至多一票 |
| 房产实勘及档案风险快照 | Supabase 账户记录 | 登录后在线读取 | 云端保留 | 风险仅新增／坐标变化时重算，查询失败不阻止保存；不冒充新地点风险 |
| 房产照片 | Supabase Storage 与实勘元数据 | 在线读取 | 云端保留 | 相机／相册采集后在线上传，不建立持久化待传队列 |
| 房产回收站 | Supabase 软删除记录及保留照片 | 登录后在线读取 | 云端保留 | 可恢复；确认永久清空时删除记录和照片，这属于用户主动业务删除 |
| 基础设施三个 ICI 权重 | Supabase 账户记录 | 登录后在线读取 | 云端保留 | 医疗／教育／交通，默认 5，只影响基础设施单点 ICI |
| 五项评估偏好及个人化适配度 | 已排除 | — | — | 删除界面、保存逻辑和数据依赖 |

## 技术与数据责任

- Supabase 保存用户业务记录及记录归属。登录同一账户可在线读取已保存数据，无需本机同步框架。
- SQLite 用于公共分析缓存；KV 用于语言与小型设置。两者都有明确的课程与业务用途。
- 已通过 SDK 保持登录时，公共分析仍可按原有缓存规则离线展示；收藏、预算、实勘、隐患写入与照片上传要求在线，失败给出反馈，不排队或自动重放。
- 退出仅执行基础当前设备退出及普通页面生命周期处理。新账号页面按当前身份重新读取记录。
- 清空回收站和单张照片删除仍是真实业务操作；存储与元数据部分失败时不宣称全部完成，可在线重新尝试，不为其建立后台队列或独立恢复模块。
- Flutter 本机存储沿用 sqflite、path_provider 和 shared_preferences，不为精简新增 ORM、后台同步、安全存储或原生桥接框架。
- 政府数据仍按既有范围一次性导入，不添加运营期自动更新。OSM／GTFS 的来源、日期和既有缓存边界保留。
