# 数据保留与账号隔离

本表是 UI 原型阶段的研究边界和目标数据责任说明，不是已完成的持久化验收结果。正式开发尚未开始；“远端用户数据”“本机缓存”等字段表示产品设计意图或原型所展示的概念，不能证明已有服务链路。

| 内容 | 当前保留位置 | 重启后 | 退出再登录 | 账号隔离 | 关键限制 |
| --- | --- | --- | --- | --- | --- |
| 认证会话 | 认证 SDK | 通常保留 | 退出后清除会话 | 是 | 由远端认证配置决定注册后是否立即有会话 |
| 语言 | 内存 | 丢失并回中文 | 同进程保留 | 否 | 翻译覆盖不完整 |
| 首页/地图 Tab 与页面状态 | 内存 | 丢失 | 同进程可能保留 | 否 | 退出后重新登录可能仍停在地图 |
| 当前选点、地点 A、地点 B | 内存 | 丢失 | 同进程保留 | 否 | 当前原型已使用 A/B；退出后仍需清理业务状态 |
| 收藏地点 | 原型内存布尔值 + 固定示例列表 | 丢失并重建示例 | 同进程保留 | 不适用 | 正式收藏记录、同步和账号隔离尚未开发 |

| 预算预案 | 远端用户数据 | 保留 | 按登录用户读取 | 是，但内存选择可能残留 | 当前 UI 不完整编辑金额 |
| 临时月预算输入 | 页面内存（当前原型） | 丢失 | 丢失 | 否 | 重开发移除；预算压力和适配度只读取当前评估预案 |
| 隐患报告本体 | 固定示例/页面内存 | 丢失并重建示例 | 不适用 | 不适用 | 正式提交、公共图层和账号管理尚未开发 |
| 隐患投票/主地图临时删除 | 内存 | 丢失 | 同进程状态可能残留 | 否 | 刷新会被远端覆盖 |
| 房产、草稿、照片 mock | 原型内存 | 丢失并重建示例 | 同进程可继续存在 | 否 | 当前没有回收站或真实持久化 |
| 房产“照片” | 内存 mock 值 | 丢失 | 同进程共享 | 否 | 不是相机/相册文件 |
| 社会经济收入输入 | 未实现（当前原型） | — | — | — | 重开发保存为当前账户评估预案私有字段，可编辑和删除 |
| 基础设施权重 | 内存 | 丢失 | 同进程保留 | 否 | 三个可见滑块 |
| 默认地点 | 页面实例内存 | 丢失 | 关闭页面即丢失 | 否 | 不影响其他功能 |
| Saved Comparisons | 固定示例 | 每次出现 | 每次出现 | 否 | 非用户数据 |
| 评论/点赞数量 | 固定常量 | 每次出现 | 每次出现 | 否 | 非真实统计 |

## Agent 判断规则

- “能在界面看到”不等于“能跨重启保留”。
- “上传云端”不等于“支持换设备恢复”；收藏当前只有上行同步。
- 公共分析数据的本机缓存不等于用户数据持久化。
- 退出登录当前不会清理多数业务内存；处理账号切换时必须显式考虑数据泄漏。
