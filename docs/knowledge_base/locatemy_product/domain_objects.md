# 核心业务对象

本文件描述产品概念，不规定数据库或代码结构。

## Location 地点

- 名称与地理坐标。
- 可承担：当前选点、地点 A、地点 B、收藏地点、房产地点或默认地点。
- 当前实现中这些角色不是同一套可靠契约；分析页可能读取不同角色或回退到固定地点。

## Location Analysis Scope 地点分析范围

- 一个地点是用户选择的坐标；每个结果使用其明确规定的官方地理单位或固定半径。
- 公共交通使用坐标周围 1.5 公里，周边设施使用坐标周围 2 公里，治安与犯罪使用地点所属统计州，其他地区统计可使用行政区。每个分析结果必须标明口径，不能把地区均值表述为该坐标的精确属性。

## Saved Location 收藏地点

- 标识、账户归属、名称、坐标、创建/更新时间和同步状态。
- Supabase 是权威来源；SQLite 只保存按账户隔离的缓存与离线创建队列。前台双向同步支持跨设备恢复、重试及删除传播。

## Budget Scenario 预算预案

- 预案标识、名称、可选的非负额外生活开销、住房支出、交通支出、月净收入、家庭月度总收入和更新时间。
- 月净收入只用于个人预算压力；家庭月度总收入只用于社会经济的州级家庭收入位置。二者都可缺失，不能互相替代；旧预案缺少任一字段时保持缺失。
- 当前评估预案由账户在远端权威记录中至多选定一份并跨设备恢复；删除 current 后保持无 current，直到用户显式选择仍存在的预案。
- 临时“当前月支出”输入不属于重开发中的预算预案。
- 它是预算压力和个人化地点适配度的必要输入；页面临时月支出不改变该选择。

## Assessment Preferences 评估偏好

- 账户级的五项优先级：安全、成本、日常便利、公共交通可达性和基础设施。
- 五项均为必填整数 `1–10`；`1–3` 为低优先级，`4–6` 为中优先级，`7–10` 为高优先级。
- 新账户及无法证明曾由用户确认的旧记录均为**未配置**；界面可将 `5` 作为预填值，但它不是已保存偏好。用户一次成功确认全部五项后才成为**已配置**，并可作为个人化地点适配度输入；之后的有效修改保持已配置。跨设备以远端已配置快照为准。
- 用于计算个人化地点适配度；不是单次对比或单个地点的临时权重。

## Personalized Location Suitability 个人化地点适配度

- 基于评估偏好、当前评估预案和可用地点分析结果的 0–100 分，不是普遍客观的宜居评分。
- 五个主读数依次为安全指数、个人预算压力转换分、2 公里五类设施覆盖转换分、交通连通性分和中性权重下的 ICI；成本转换分为 `100 − clamp(PersonalBudgetBurden(%), 0, 100)`，设施转换分为 `100 × 已确认覆盖类别数 ÷ 5`。
- 每个可用维度的权重乘数为 `preference ÷ 5`，总分为可用维度按其权重重新归一化后的加权平均；不复用 ICI 内部的医疗、教育和交通优先级。
- 缺少中或高优先级维度时不可计算；缺少低优先级维度时可不纳入，并说明覆盖情况。若所有维度均不可用或可用权重为零，显示“个人化地点适配度暂不可用：目前没有可用的评估维度”，不显示 0 分或部分分。
- 没有当前评估预案时不可计算；预案缺少住房、交通或月净收入，或生活篮子在最近 12 个月内可用月份少于 6 个月、平均覆盖率低于 80% 时，成本维度缺失。明确为 RM 0 的住房或交通视为已填写。
- 周边设施任一类别为未知时，日常便利维度缺失；无有效路线或交通资料不完整时，公共交通维度缺失；明确零值保留为 0。
- 地点对比中仅当两个地点都可计算时才可并列展示；不以此自动判定赢家或推荐地点。

## Hazard Report 隐患报告

- 类型：`flood`、`crime`、`traffic`、`infrastructure`、`other`。
- 标题、描述、位置、上报时间、上报用户、处理状态和赞成/反对读数。
- 标题去空白后必填；发布后类型、标题、描述、位置和上报时间不可编辑。状态为创建者可管理的 `pending` 或 `resolved`；所有登录用户可读，只有创建者可更新自身状态或删除。
- 每个登录账户对同一报告至多有一条可撤回的投票；读数由投票记录计算。

## Property Inspection 房产实勘

- 名称、价格、收藏地点、综合评分、水灾历史。
- 排水、防水、湿度、照明四项 1–5 星评分。
- 照片是仅归属于该实勘、且仅创建账户可见的视觉证据；一份实勘最多 20 张。照片可有自由文字说明及一个封面，但不带结构化标签。照片保留 EXIF，LocateMY 不读取或展示 EXIF 内容。
- 备注。
- 统计州、州级安全指数和附近隐患数等风险摘要。
- 正式生命周期为软删除至回收站、恢复或确认后永久清空；清空同时删除照片文件。
- 当前整个对象只存在于原型内存；代码初始展示 3 条演示房产。

## Location Comparison 地点对比

- 两个不同地点（地点 A 与地点 B）及各自分析结果构成的并列比较；交换只改变呈现顺序，不改变结果含义。
- 总览包含生活成本、治安与犯罪、社会经济、基础设施、周边设施和公共交通；每类先显示可解释的主读数，再进入分项详情。
- 只有两边资料可用且统计口径一致时才可计算差异；否则显示资料缺失或口径不可比的原因、来源和日期。
- 当前地图两端只在内存，账户中的 Saved Comparisons 是固定示例，二者没有连接。
- 不能与 Property Comparison 混同；房产对比比较的是 2 个以上房产记录。

## Analysis Result 分析结果

- 宏观经济、生活成本、治安、社会经济、基础设施、周边设施和公共交通属于不同结果域。
- 部分远端公共结果带本机缓存，但不属于用户创建的数据。
- 展示数值不等于其算法或统计口径已在本知识库中定义。

## Infrastructure Coverage 基础设施覆盖

- 基础设施综合覆盖指数（ICI）是单个地点获得供水、供电、医疗、教育和公共交通服务的相对程度，范围为 0–100。
- ICI 是覆盖可获得性的产品模型，不是服务质量评分、政府评级或个人化推荐。
- 服务覆盖分项缺失表示资料未知；真实的零值表示观测到数量为零。

## Transit Coverage 公共交通覆盖

- 以地点坐标为中心、半径 1.5 公里的 GTFS Static 站点与有效服务路线覆盖读数。
- 交通连通性分数表示相对覆盖，不表示通勤时间、票价、准点率、班次密度或服务质量。
- 站点实体与路线按各自 feed 及原始 ID 识别；不同 feed 的同名实体不自动视为同一对象。

## Transit Feed Snapshot 交通 Feed 快照

- 某次同步取得的 GTFS Static feed、采集时间、解析状态和有效服务日期。
- 快照可过期但仍可读；解析失败或预期 feed 缺失会使交通分数不可用，并保留已成功取得的结果作为部分展示。
