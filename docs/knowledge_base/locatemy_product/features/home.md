# 首页

## 目的

向用户展示整体搬迁环境摘要，并引导进入地图选址。

## 当前 UI 原型功能

- 搬迁时机标签、搬迁建议、原因说明和搬迁指数，数值为固定示例。
- 成本压力、就业稳定度和经济动能三张固定示例卡；当前没有真实趋势图或数据服务。
- 家庭收入中位数固定示例卡。
- “探索马来西亚”切换到地图 Tab；搜索框也只进入预设地点选择流程。
- 顶部显示语言图标和账户入口；语言图标无有效回调。
- 当前代码没有刷新按钮，也没有下拉刷新处理。

## 目标刷新行为（当前原型未实现）

- 目标是顶部刷新按钮刷新整组首页统计并重新生成搬迁指数。
- 目标是支持下拉刷新。
- 目标是成功强制刷新后进入 60 秒冷却。
- 目标是按钮刷新期间显示转圈并禁用；冷却期点击提示剩余秒数。

## 数据边界

- 首页结果可在本机缓存；缓存记录其数据集日期，在线时优先替换为数据集日期更近的结果。
- 冷却计时只在内存。
- 正式开发中 Flutter 从 Supabase 的只读接口读取维护者在 Flutter 开发前一次性手动导入的政府开放数据；直至项目完成不更新，且不实现自动同步。指数规则见 [首页宏观指数](../home_index_scoring.md)。
- 当前 UI 原型仅展示示例数值，尚未开始真实数据服务接入，不能把示例内容描述为官方实时统计。

## 重开发要求

- 保留所有可见宏观指标、趋势图、建议卡和地图入口。
- 数值必须标明数据集日期，不以 Supabase 刷新时间判断或展示数据新旧。
- 刷新入口的冷却和反馈在按钮与下拉手势中应一致。
