# 账户中心

## 当前 UI 原型展示内容

- 展示固定的用户姓名、邮箱和“邮箱已验证” Chip；这是资料卡示意，不是认证服务结果。
- Property Inspection Portfolio 进入房产实勘档案原型。
- My Reported Hazards 进入隐患报告列表原型。
- 五项评估偏好滑块：安全、成本、日常便利、公共交通可达性、基础设施；原型展示 `1–10` 分层和个人化地点适配度设置意图。
- 当前评估预案行展示篮子倍率、住房、交通和月净收入摘要，并可进入生活成本页。
- 语言行和退出入口被展示出来，但正式语言偏好和会话结束尚未开发。

## 原型限制

- 头像是占位图。
- Verified User 固定显示，不读取真实邮箱验证状态。
- 个人资料、偏好和评估预案尚未连接账户服务。
- 房产和隐患页面是原型内容；正式账号隔离、持久化和同步尚未开发。

## 原型中未展开的入口

- Relocation Assessment History：空回调，无页面或数据。
- Default Location：只改变本页开关，关闭页面即重置，不影响其他功能。
- Saved Comparisons：两条固定示例，点击无效，与地图或房产对比无连接。
- My Comments：固定数字 3，无评论功能或详情页。
- Liked Areas：固定数字 12，无点赞功能或详情页。

## 重开发要求

- 保留真实邮箱、房产/隐患入口和确认退出。
- 真实修复验证状态和退出后的账号数据隔离。
- 增加账户级评估偏好设置：安全、成本、日常便利、公共交通可达性和基础设施五项必填 `1–10` 优先级；`1–3` 为低、`4–6` 为中、`7–10` 为高。
- 账户保存并可切换当前评估预案；预案保存统一生活篮子调整、住房支出、交通支出和月净收入。地点详情展示预案名称，并据此计算个人化地点适配度。
- 占位内容不得描述为已实现，也不得直接复制固定示例。
- `ACCOUNT-08` 账户评估偏好：五项必填 `1–10` 优先级属于账户级数据，按账户隔离持久化；它是个人化地点适配度的唯一偏好来源。
- `ACCOUNT-09` 当前评估预案：账户保存一份当前选中的预算预案，可按账户切换并持久化；地点详情据此显示预算压力与适配度。
- 搬迁评估历史、默认地点、保存的对比、评论和点赞统计（`ACCOUNT-03`–`ACCOUNT-06`）归类为 `excluded`，本次不实现，也不得保留固定示例或空回调控件。
