# 登录与注册

## 历史 UI 原型：登录

- 展示邮箱和密码两个字段。
- 展示“登录（演示）”入口和进入注册页的链接。
- 原型按钮直接回到首页；没有真实认证、字段校验、加载、错误反馈或会话建立。

## 历史 UI 原型：注册

- 展示用户名、邮箱、密码和确认密码四个字段。
- 展示“创建账户（演示）”入口和返回登录页的链接。
- 原型按钮直接回到首页；没有真实注册、校验、成功反馈或会话建立。

## 历史 UI 原型：账户验证与退出

- 账户页显示固定邮箱和“邮箱已验证” Chip；不能用来判断真实验证状态。
- 退出入口展示为账户页列表项；当前只是跳到登录页，不代表真实会话已清除。

## 中英文支持

Authentication 的中英文支持遵循 [统一双语与内容规则](../ui_design_spec.md#双语与内容规则)。覆盖登录、注册、表单校验、加载、成功与失败反馈、退出以及品牌说明。语言入口可使用，偏好跨重启与退出保留。邮箱验证界面和验证徽章取消；Magic Link、游客模式和忘记密码不因双语支持而加入范围。

## 正式开发边界

- 2026-09-17 用户确认最小账号边界：保留邮箱密码注册、登录、退出、SDK 默认保持登录及当前用户身份。
- 取消注册邮箱确认要求、待验证分支和验证徽章；基础认证及 SDK 内部会话仍保留。
- 取消项目自行构建的会话管理、独立 Account Privacy 与跨 Feature 清理证明／恢复流程。退出不以本机私有数据删除作为完成条件；按当前用户读取其记录的基础行为仍保留。
- Magic Link、游客模式和忘记密码不属于默认范围。
