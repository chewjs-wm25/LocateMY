# 登录与注册

## 历史 UI 原型：登录

- 展示邮箱和密码两个字段。
- 展示“登录（演示）”入口和进入注册页的链接。
- 原型按钮直接回到首页；没有真实认证、字段校验、加载、错误反馈或会话建立。

## 历史 UI 原型：注册

- 展示用户名、邮箱、密码和确认密码四个字段。
- 展示“创建账户（演示）”入口和返回登录页的链接。
- 原型按钮直接回到首页；没有真实注册、校验、成功反馈或会话建立。

## 历史 UI 原型：账户验证与退出

- 账户页显示固定邮箱和“邮箱已验证” Chip；不能用来判断真实验证状态。
- 退出入口展示为账户页列表项；当前只是跳到登录页，不代表真实会话已清除。

## 中英文支持

Authentication 的中英文支持遵循 [统一双语与内容规则](../ui_design_spec.md#双语与内容规则)。覆盖登录、注册、可选用户名、表单校验、注册后邮箱验证提示、用户名保存反馈、会话恢复与不可用状态、真实邮箱验证状态、退出确认与失败重试，以及品牌说明。语言入口在认证各状态下均可使用，偏好跨重启与退出保留。

邮箱验证邮件的正文由认证服务邮件模板管理，不属于本次应用界面翻译范围；界面中的验证提示必须双语完整。Magic Link、游客模式和忘记密码不因双语支持而加入范围。

## 正式开发边界

- 保留邮箱密码认证和现有字段规则，除非产品另行修改。
- 注册结果必须区分“已建立会话”和“需要邮箱验证”。
- 验证徽章必须绑定真实验证状态，或从界面移除。
- 退出或切换账号时清理所有账号相关内存，避免前一账号数据泄漏。
- Magic Link、游客模式和忘记密码不属于默认范围。
