# 房产实勘

## 当前 UI 原型定位

房产模块展示新增、详情、编辑、照片、对比和三种档案浏览方案，但全部是 UI/内存原型，不能视为正式用户数据功能。当前原型没有房产软删除或回收站页面；正式实现必须补齐，见下方承诺基线要求。

## 新增与编辑字段

- 房产名称：必填，无限长。
- 价格：只检查非空；非数字会保存为 0。
- 地点：当前 UI 从两个预设地点选择。
- 排水、防水、湿度、照明：各 1–5 星，默认 3 星。
- 综合评分：由四项平均生成，无独立输入。
- 当地水灾迹象：布尔开关，默认关闭。
- 照片占位项：可添加多个 mock 项、删除、设为主图、编辑说明并展示同步状态。
- 备注：可空。

## 地图选点

- Pick on Map 直接退出表单并切换地图 Tab，不是返回结果式选点。
- 新增时名称、价格、收藏 id 和四项评分会写入内存草稿。
- 备注、水灾开关和照片不进入草稿。
- 用户需要在地图选点/收藏后，再从治安页重新进入表单。
- 只有选点靠近某收藏时才自动选择该收藏；普通未收藏点不能直接回填。
- 编辑模式未保存修改不会完整保留。

## 当前 UI 原型照片

- 相机和相册按钮只生成本地 mock 照片对象，不读取设备媒体。
- “照片”是 `InspectionPhoto` 记录和占位图，不是真实照片文件。
- 原型展示 20 张上限、删除、封面、说明和同步状态等产品意图；上传、压缩、EXIF 和云端同步尚未开发。

## 已确认的照片重开发设计

- 照片是房产实勘的私有视觉证据，不是房源图片或公开内容；仅创建该实勘的账户可见。
- 新增和编辑实勘均可从相机或相册添加照片。每次添加创建该实勘自己的副本，绝不影响设备相册原图；每份实勘上限为 20 张，达到上限时阻止继续添加并说明需先删除现有照片。
- 首版仅接收常见格式的静态照片，并在上传前统一压缩。照片保留原始 EXIF，但 LocateMY 不读取或展示其中的拍摄时间、位置或其他资料。
- 每张照片可附自由文字的照片说明，不使用结构化标签或圈选标注。用户可指定一张封面；其他照片按添加时间排序。删除封面时，最早添加的剩余照片自动成为封面；没有照片时展示默认占位。
- 档案列表展示封面，实勘详情展示完整照片库，房产对比仅展示各实勘封面。
- 实勘进入回收站时，其照片一并保留；清空回收站时，实勘及其照片永久删除。单张照片删除后不进入回收站；首版删除必须在线完成，失败时保留原照片并提供重试反馈，不建立离线删除队列。
- 无网络时先将照片保存到本机，恢复网络后自动同步。同步状态必须可见；同步失败时用户可手动重试，本地副本继续可查看。
- 首版不提供单张或整份实勘的照片导出、分享功能。

## 风险资料

- 原型详情直接展示固定/字段级风险摘要；没有真实风险查询流程。
- 详情展示地址、价格、综合评分、安全分、警区、水灾、四项评分、照片和备注。
- 对比展示价格、安全分、水灾、附近隐患数、综合评分和四项评分。

在当前 UI 原型中，“安全分 0–100”和“附近隐患数”只是房产记录字段的示例展示，没有独立公式或当前数据源，不能与治安页面的安全指数混同。综合评分才按四项现场评分平均展示；它是用户实勘记录，不是地点指数。

## 档案浏览与回收站边界

- 档案页展示三种原型方案：决策概览、看房日志、对比挑选。
- 原型显示 3 条预设房产，可进入详情、编辑和选择对比；没有搜索、排序或地点筛选。
- 当前没有房产删除、回收站、恢复或 Clear All 控件；这些不能作为当前页面功能描述。

## 房产对比

- 从档案进入多选模式。
- 最少选择 2 项；当前原型最多选择 3 项。
- 结果不保存，也不进入账户 Saved Comparisons。

## 数据边界

- 房产、草稿、照片 mock 全在原型内存中。
- 重启后重新显示演示数据；没有真实账号归属、持久化或同步。

## 重开发要求

- 保留房产实勘、档案、详情、编辑和对比的产品能力。
- 不得沿用内存跨账号数据、固定风险预览和 mock 照片。
- 照片须按本文件的“已确认的照片重开发设计”实现真实持久化、账号归属、采集/上传与离线错误回退。
- 房产实勘新增、编辑、档案、详情、多选对比和草稿续填均为[大学提交承诺基线](../submission_commitments.md)锁定的能力；至少支持两项并排对比。
- 删除必须进入可见回收站，支持恢复及确认后的永久清空；清空同时永久删除照片文件。
- 创建或坐标变更时保存风险快照；详情显示快照/数据时间并提供显式刷新，不静默覆盖历史记录。
