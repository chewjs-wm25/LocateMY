# 房产实勘

## 已确认的产品范围（2026-09-17）

保留新增、编辑、档案、详情、2–3 份记录并排对比、真实照片，以及可见回收站、恢复和确认后的永久清空。账号记录只在线读写 Supabase；删除跨重启草稿恢复、照片待上传队列、自动同步和跨 Feature 退出清理证明。

本文件描述目标产品行为。历史原型仅有内存记录与 mock 照片；本次调查未见房产实勘对应生产 Feature，不以现有数据库表或本次范围决定作为实现完成证据。

## 表单与地点

- 名称、地址／坐标、非负价格、排水／防水／湿度／照明四项 1–5 星、水灾迹象和备注。
- 综合评分为四项现场评分的平均，不是地点安全指数。
- 地点可从收藏选择或经地图返回式选点取得。当前表单在地图往返期间保留，不承诺杀进程或重启后恢复。
- 新增、普通编辑与坐标修改显示加载、成功和失败。云端保存失败时，不将未保存内容标成成功，可在当前页面修正或重试。

## 档案风险快照

- 档案保存统计州、州级安全指数、附近隐患数及其采集时间／可用性，反映新增或改变坐标时的上下文。
- 仅新增实勘或实际改变坐标时重新计算并保存；修改名称／评分／备注、查看详情和重启不重算。
- 不提供手动刷新，也不自动补算查询失败的快照。
- 风险输入缺失或查询失败仍允许保存实勘；明确标记快照不可用，不以假数据或零补齐。坐标改变后，旧地点风险不得冒充新地点风险。
- 州级安全指数来自治安业务；附近隐患数沿用隐患事实源的 2,000 米及 pending 口径。隐患不进入官方安全指数。

## 照片

- 新增／编辑可从相机或相册取得常见静态照片并压缩后在线上传至 Supabase Storage，实勘元数据保存说明和封面。
- 每份实勘最多 20 张；不改动设备相册原图。照片归属当前账户的该份实勘。
- 照片允许自由文字说明、一张封面和单张删除；其余按添加时间排序。删除封面后以最早剩余照片替代，没有照片则显示占位。
- 列表和对比显示封面，详情展示照片库。照片不提供分享、导出、结构化标签、圈选或 EXIF 展示。
- 显示在线上传与删除的加载、成功和失败反馈；当前表单可重新尝试，失败不称为保存成功。取消离线待传、自动重放和跨重启待上传恢复。
- Storage 与元数据部分失败时保留真实反馈；不为故障建立独立恢复模块或持久化队列。

## 回收站与对比

- 删除先软删除进入可见回收站，照片保留；恢复后记录与照片重新出现在档案中。
- 用户确认永久清空后，删除回收站内的实勘、照片元数据与 Storage 文件；部分失败不称为全成功，允许在线重新尝试。
- 对比选择 2–3 份当前账户的活动记录，展示价格、评分、照片封面、水灾和档案风险快照；不保存对比结果。
- 退出账号不等同于清空回收站，不自动删除云端业务记录或本机预算导出文件。
