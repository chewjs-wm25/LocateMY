# 隐患上报与管理

## 原型页面边界

隐患报告由独立的隐患功能负责。治安与犯罪页面不展示隐患类型筛选或隐患图层，隐患报告也不进入官方安全指数。

## 当前 UI 原型：新建报告

- 可从示意地图上的“上报隐患”按钮打开；长按地图不是当前原型交互。
- 类型：Flood、Crime、Traffic、Infrastructure、Other。
- 原型页面当前视觉上选中“水灾”；正式表单不预选类型，类型为必填项。
- 字段：类型、标题、描述、地理位置。
- 原型展示标题必填、描述可空和地点字段；类型 Chip 与字段校验仍是待开发行为。
- 原型提交按钮只跳转到“我的隐患报告”示例列表，不创建真实报告。
- 远端保存、成功/失败反馈、账号归属和同步尚未开发。

## 当前 UI 原型：报告列表与地图隐患意图

- “我的隐患报告”页面展示两条固定示例报告。
- 原型没有地图隐患图层、详情页、刷新、定位或投票交互；这些只属于功能意图/后续开发范围。

## 投票与详情删除（当前原型未实现）

- 赞成/反对只修改内存，刷新或重启后丢失。
- 详情红色按钮文案类似“取消”，实际只做内存删除；远端刷新后报告重新出现。
- 以上均是原型行为，不可描述为可靠功能。

## 我的隐患报告（当前原型）

- 展示报告列表的页面意图、类型、日期、描述和地点示例。
- 当前记录固定写在原型页面中，不代表当前用户的远端报告。

## 重开发要求

- [大学提交承诺基线](../submission_commitments.md)要求保留五类上报、地图显示、详情和本人报告管理；不得再将地图图层、详情或投票列为待决定。
- 标题使用去空白校验，并为字段设置合理限长。
- 提交必须有加载、成功和失败反馈。
- 类型名称必须国际化。
- 所有登录用户可读取公共图层；报告发布后 type、标题、描述、位置和上报时间不可编辑，创建者只能更新自己的处理状态或删除自己的报告。地图未选地点时不加载公共隐患图标；选点后仅展示当前选中地点周围 2,000 米圆形范围内的隐患（含边界），可分页读取。平移、缩放或旋转不扩大该地点范围。
- 状态仅为创建者可管理的 `pending` 或 `resolved`，不建立审核、隐藏或删除特权。创建提交前可修正表单输入；成功发布后内容不可变。
- 投票必须持久化：每个登录账户对同一报告只能赞成、反对或撤回一次，计数从投票记录计算。

## 房产风险快照的附近隐患数

`HAZARD-002` 为房产风险快照提供一个地点的附近公共隐患数。它固定使用房产坐标为中心的
2,000 米 Haversine 圆形范围，距离 `d <= 2,000m` 包含边界；只统计公开且处理状态为
`pending` 的报告，`resolved` 不计入。结果必须携带半径、统计时间和可用性。失败或不完整
结果是不可用，不能以 `0` 代替；此读数不改变公共图层、官方安全指数或报告状态。
