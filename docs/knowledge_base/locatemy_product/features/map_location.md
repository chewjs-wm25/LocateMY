# 地图、选址与收藏

## 当前 UI 原型的地图工作区

- 地图区域是标注“示意”“非真实比例”的静态地图插图，不支持真实地图浏览、缩放、移动或普通点击选址。
- 搜索框和“选吉隆坡/选乔治市”入口只打开预设地点选择；没有地点自动补全、马来西亚范围校验或坐标查询。
- 当前选点只有两个预设 `Place`，只保存在进程内存。
- 单点模式展示地点摘要入口、收藏切换、完整分析入口、两地比较入口和上报隐患入口；摘要的数值、状态和原型缺口见[完整性审计矩阵](../completeness_audit.md)。

## 当前 UI 原型的对比模式

- 用户可在地点 A、地点 B 选择器中使用两个预设地点。
- 支持清空单侧、交换 A/B，并阻止相同地点进入比较。
- “查看地点比较”在两端有效且不相同时可进入比较总览；A/B 只表示呈现顺序，不表示搬迁方向。
- 对比插图使用两个固定位置标记，不是真实地图。

## 当前 UI 原型的快捷入口

- 地图页顶部只有已保存地点入口。
- 单点区域有“上报隐患”按钮；它只跳转表单，不从长按坐标生成位置。
- 当前没有远端隐患刷新、隐患图层切换、全局清除或六类分析面板快捷按钮。

## 当前 UI 原型的收藏地点

- 地点详情卡上的“收藏”只切换一个内存布尔值，不创建带名称、坐标或时间戳的收藏记录。
- `SavedPage` 显示两条固定预设地点；搜索框、删除、同步和恢复没有有效实现。
- 收藏页面点击地点只回到地图并切换当前预设地点。

目标的本机保存、云端上传、账号隔离和双向同步仍属于重开发决策，不能描述为当前功能。

## 六类分析入口

- 生活成本、治安、社会经济、基础设施、周边设施、公共交通。
- 当前原型可打开单点六类分析，也可从有效的地点 A/B 进入六类比较总览；各分析仍可能使用示例 fixture。
- 无选点时部分页面仍可能使用固定默认地点，这是已知缺口，不是目标行为。

## 地点分析审计后的当前原型边界

- 地点摘要展开态固定展示安全、生活成本、周边设施、公共交通和 ICI 五项；社会经济只在专属分析页展示。安全项当前为“暂不可用”，其余项为本地 fixture 或示例状态。
- 个人化地点适配度的规则已确认，但当前 `safetyScore` 尚未接入而固定缺失；因此原型默认不生成有效总分，不得把剩余维度拼成部分总分。
- 地点 A/B 比较总览和详情的页面结构已展示，但除生活成本外的比较读数仍是硬编码示例，不能视为两个地点的实际分析结果。逐项来源、日期、单位、缺失和可比性要求见审计矩阵。

## 已确认的重开发产品决策

### 地点详情卡

- 单点选择后在地图底部显示可折叠的地点详情卡。折叠态显示地点、可用的个人化地点适配度和操作；展开态显示完整摘要。
- 展开态展示：地区安全指数、本地生活成本指数、2 km 内周边设施类别覆盖及未覆盖类别、1.5 km 内公共交通可达性、基础设施综合状态及最低或缺失分项。
- 周边设施摘要只展示五类覆盖及未覆盖类别；最近设施及距离保留在完整周边设施分析页。
- 生活成本有当前评估预案时可补充预算压力；公共交通可达性不表示实际通勤时间；社会经济只在其专属分析页展示。
- 地点详情不展示用户隐患报告，也不生成“优势／留意点”等推断性文字。
- 每项沿用原生、可解释的单位；个人化地点适配度才使用 0–100。每项都显示行政区或半径口径、数据日期及来源、缓存或估算状态。

### 个人化地点适配度

- 仅当账户已有五项评估偏好、已选当前评估预案，且中／高优先级维度都有数据时计算。评估偏好为必填整数 `1–10`；`1–3` 为低优先级，`4–6` 为中优先级，`7–10` 为高优先级。
- 低优先级缺失数据可不纳入，但必须显示其覆盖情况，并按剩余维度的 `preference ÷ 5` 权重重新归一化；未满足条件时说明需要补充的偏好、预案或数据，不用默认值补齐。
- 若所有维度均不可用或可用权重为零，显示“个人化地点适配度暂不可用：目前没有可用的评估维度”，不显示 0 分或部分分。
- 五个维度的主读数为安全指数、个人预算压力转换分、2 公里五类设施覆盖转换分、交通连通性分和中性权重下的 ICI。生活成本指数是地点成本辅助读数，不直接作为个人适配度分数。
- 成本转换分为 `100 − clamp(PersonalBudgetBurden(%), 0, 100)`；设施转换分为 `100 × 已确认覆盖类别数 ÷ 5`。设施类别未知时日常便利维度缺失，不能把未知当作未覆盖。
- 每个偏好为必填整数 `1–10`，权重乘数为 `preference ÷ 5`。适配度为可用维度按其权重重新归一化后的加权平均，不复用 ICI 内部的医疗、教育和交通优先级。
- 没有评估预案时适配度不可用；预案缺少住房、交通或月净收入，或生活篮子在最近 12 个月内可用月份少于 6 个月、平均覆盖率低于 80% 时，成本维度缺失。住房或交通明确为 RM 0 视为已填写。成本资料部分可展示金额和覆盖率，但地点详情须说明“部分篮子资料，成本维度未纳入适配度”。

### 地点详情操作

- 详情卡只提供收藏、查看完整分析和发起两地比较。
- 发起比较时，用户将当前地点设为地点 A 或地点 B，再选择另一地点；不得静默决定比较方向。

## 重开发要求

- 建立统一地点角色：单点、地点 A、地点 B、收藏和分析目标。
- 所有分析入口必须明确前置地点并禁止静默使用互不一致的默认地点。
- 收藏必须决定账号隔离、离线使用和双向同步策略。
- 对比模式以中性的地点 A/地点 B 呈现，提供一键交换、阻止相同地点比较，并保留切换模式时的另一模式地点。
- 两个地点均有效后，入口进入六类地点分析的比较总览，而非只进入生活成本比较。
