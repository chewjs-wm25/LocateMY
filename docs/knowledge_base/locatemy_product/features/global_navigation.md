# 全局导航与语言

## 2026-09-17 已确认的精简边界

继续要求登录后进入主应用；保留首页／地图双 Tab、普通子页面、中英文切换与本机语言持久化。使用普通 Flutter 路由、明确参数和具名业务服务；取消账户范围开关、清理屏障／恢复页面和通用导航意图／贡献框架。退出执行当前设备基础退出并结束普通业务页面，不删除预算 JSON 或等待跨模块清理证明；新账号页面按当前用户读取记录。

## 历史 UI 原型功能

- 应用启动直接进入首页；当前代码没有按认证状态阻挡主应用。登录页和注册页是可进入的演示页面。
- 主应用只有“首页”和“地图”两个一级 Tab。
- 两个 Tab 在同一进程内切换时通常保留滚动、地图和局部页面状态。
- 首页顶部显示语言图标和账户入口；语言图标没有有效回调，账户页的语言行也没有有效回调。
- 当前可见文案基本是中文，没有可验证的中文/English 切换行为。

## 历史原型边界

- 导航索引只在内存。退出演示登录只是跳转到登录页，不清理地点、房产或其他业务状态。
- 语言默认中文，只在内存；完整重启会回到中文。
- 当前原型没有实际语言切换；账户、房产、隐患和分析文案仍混有固定中文/英文。
- 子页面不是一级 Tab，通过页面跳转进入。

当前原型没有独立的刷新按钮或认证门控；这些属于目标行为时，必须在重开发要求中单独说明，不能列为当前可用功能。

## 重开发要求

- 保留认证门控和双 Tab 产品结构。
- 登录/退出时明确重置或恢复导航状态，不得无意继承前一账号上下文。
- 中英文支持统一遵循 [双语与内容规则](../ui_design_spec.md#双语与内容规则)，包括语言默认值、切换、持久保存、覆盖边界和验收要求。
