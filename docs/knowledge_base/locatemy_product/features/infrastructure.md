# 基础设施

页面辅助信息按 [UI 精简边界](../ui_design_spec.md#分析页面精简边界2026-09-17) 呈现；本轮不改变本文件的指标、公式、取数、缓存与可用性语义。统计年份可集中标示，来源与技术错误字段保留内部用途。

## 当前功能

- 展示基础设施综合覆盖指数（ICI）。
- 展示供水、供电、医疗、教育和公共交通分项。
- 数据缺失时显示 `—`、数据不完整徽章和缺失说明。
- 可调医疗重要性、教育优先级和交通便利性三个滑块。
- 滑块变化会即时更新综合结果。
- 单点页面的 ICI 使用当前地点 fixture 和页面滑块；地点摘要另以医疗、教育和交通均为 5 的中性优先级计算摘要 ICI。

## 权重行为

- 三个可见滑块显示 1–10 的调整标签。
- “交通便利性”控制公共交通分项权重。
- 供水和供电参与计算，但没有可见滑块。
- 分项卡显示原始分项结果，不随权重变化；综合结果会变化。
- 权重只在进程内存中保留，重启后丢失；重开发改为按账户保存的全局权重。

## 缺失数据行为

- 适用但缺少数据的分项按缺失处理并在界面列出。
- 单项显示 `—`，综合卡仍可能显示参考分数。
- 数据不完整徽章不可点击。
- 坐标无法可靠取得行政区或交通范围时，相关分项标记缺失；不能把缺失当作 0。

## 地点边界

- 当前原型的单点分析使用选中地点；地点比较使用地点 A/B，总览和详情中的部分数值仍为示例 fixture；无有效选点时可能回退固定地点。
- 地点比较总览和详情当前使用硬编码 ICI 示例，未读取 A/B 的单点 `InfrastructureAnalysisResult`，也未传递真实缺失分项、最低分和各分项日期；不能将其写成 A/B 的实际 ICI 结果。

## 重开发要求

- 保留综合、分项、缺失提示和个性化权重。
- 单点页只分析一个地点；地点对比以 A/B 并列综合覆盖指数和相同分项，资料不完整或不可比时不得计算差异。
- 明确每个权重对应的分项；“交通便利性”必须明确控制公共交通分项。
- ICI 权重按账户保存为一份全局权重（医疗、教育、交通），未设置时默认中性值 5。合法滑块变化立即产生仅本页可见的 `unsaved preview` 单点 ICI；保存失败时草稿/预览保留，可重试或恢复最后一次已保存值。只有远端保存成功才发布跨设备的已保存变化。权重不改变地点摘要与 A/B 使用的中性 ICI；2026-09-17 已删除 `ACCOUNT-08` 五项评估偏好，三个 ICI 权重仍保留并在线保存。
- 地点 A/B 的基础设施综合读数一律使用医疗、教育、交通均为 5 的中性 ICI；账户自定义权重不进入 A/B，也不用于自动判定地点优劣。
- ICI 公式、数据集 ID、字段、日期与缺失规则见 [infrastructure_index_scoring.md](../infrastructure_index_scoring.md)。
