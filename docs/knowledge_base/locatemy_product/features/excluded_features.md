# 明确排除的功能

## 独立气候与水灾模块

当前应用没有以下页面、入口或隐藏路由：

- 独立气候与水灾分析页。
- 七天天气预报。
- 实时天气或季风面板。
- 水位监控与定时刷新。
- 实时洪水警报图层。
- 历史降雨图和独立洪水风险等级。

当前与洪水相关的真实产品能力只有：

- 隐患报告中的 Flood 类型。
- 房产实勘中的人工水灾历史/迹象开关。
- 房产详情与对比中的水灾字段。

除非用户明确提出新增需求，否则不得根据旧文档恢复独立气候模块。

## 其他默认排除

- Magic Link、游客身份、忘记密码页面。
- GPS 当前定位和离线地图。
- 公共交通路线几何、班次和运营时间。
- 周边设施路线规划、营业时间和评分。
- 旧设计中没有当前截图或代码事实支撑的功能。
