# 重开发范围策略

## 默认必须保留

- 邮箱密码登录与注册。
- 首页搬迁建议、宏观指标、刷新和进入地图。
- 首页/地图双 Tab 与中英文切换。
- 马来西亚地图、地点自动补全、单点选址和两地选择。
- 收藏地点在线保存、读取、选择和删除；登录同一账户时可直接读取云端记录。
- 六类地区分析入口。
- 生活成本、治安、社会经济、基础设施、周边设施和公共交通的当前核心展示能力。
- 预算预案管理。
- 基础设施 ICI 权重按账户保存为全局权重，默认中性 5；与评估偏好分开管理，只影响基础设施单点页 ICI。
- 隐患上报、公共隐患地图、详情、每用户一票的投票和“我的隐患报告”。
- 房产新增/编辑、档案、详情、对比、真实照片和回收站／恢复。
- 房产风险快照保存于档案，仅新增或坐标变化时重算；风险不可用仍允许保存并明确标记，不自动补算或提供手动刷新。
- 预算预案导出本机 JSON 并在应用中读取展示；不自动同步或写回云端。
- 账户中的真实用户内容入口和退出登录。

## 保留产品意图，但不得照搬当前临时实现

- 房产记录、照片和回收站：采用真实在线持久化及简单的账户归属权限。
- 收藏地点：采用明确账号归属的 Supabase 记录，不保留离线创建或同步队列。
- 地点对比：单点模式的六类分析均使用单点；两地模式以地点 A/B 并列六类分析，A/B 只表示呈现顺序，不表示搬迁方向。
- 语言：统一翻译覆盖；偏好保存到本机键值存储，不绑定账号，退出登录不清除。
- 隐患投票：每账户每报告一条可撤回的持久化记录；不引入审核语义的 `verified` 或 `rejected` 状态。
- 基础设施 ICI 权重有独立用途，保留三个账户级权重；评估预案保存统一篮子调整、住房、交通、月净收入和家庭月度总收入。
- 分析默认地点：缺少合法分析地点时六类分析不可进入并提示先选择地点，不得静默混用多个固定地点或读取第二个地点。

## 已决定排除（`excluded`）

以下能力在 2026-09-13 产品范围基线中归类为 `excluded`。它们不阻塞任何当前 required 流程；重新引入必须提出明确的新增需求，并补齐数据、权限和持久化契约。

2026-09-17 用户确认新增排除：真实邮箱验证界面（`AUTH-03`）、个人化地点适配度总分（`MAP-07`）、五项账户评估偏好（`ACCOUNT-08`）、跨重启房产草稿、账号数据离线队列／自动同步／照片待上传和手动风险刷新。自建会话协调、Account Privacy 与通用导航／贡献框架也删除，架构执行依据 ADR 0017。

- 查看商家与商品下钻（`COST-04`）：商品数据只用于生活成本篮子与同名商品价格对照，不需要商家下钻。
- 周边设施详情、展开和路线（`FAC-02`）：覆盖数量与最近三项已足够支撑生活便利判断，路线属于导航范围。
- 安全地图（`SAFE-02`）：警区多边形边界资料不可获取；治安功能只保留以地点所属统计州聚合的安全指数与趋势，不提供警区或州边界图层。
- 搬迁评估历史（`ACCOUNT-03`）、默认地点（`ACCOUNT-04`）、保存的地点对比（`ACCOUNT-05`）、评论与点赞统计（`ACCOUNT-06`）：账户保留真实邮箱、当前评估预案、房产与隐患入口和退出登录。
- 保存房产对比结果：房产对比是即时选择，不进入账户数据。
- 隐患审核进度：处理状态只有创建者可管理的 `pending` 与 `resolved`。

## 默认排除

- 未在相应产品模型文件中确认的指数、归一化、预测和拟合算法说明。
- 系统架构、代码分层、缓存机制、数据库表、RPC 和第三方接入方案。
- 独立气候/水灾模块及旧文档中的天气和水位功能。
- Magic Link、游客模式、忘记密码、离线地图、GPS 定位、路线规划、交通班次。
- 旧设计中没有当前界面或代码事实支撑的其他功能。

## Agent 实施规则

1. `working` 能力可作为验收基线，但不要复制已知错误。
2. `partial` 能力应先保留用户可见意图，再根据本知识库修正边界。
3. `prototype` 只能作为产品原型参考，不能沿用其内存数据或模拟图片方案。
4. `placeholder` 不可默认为开发需求；需要用户或产品负责人确认。
5. `excluded` 只有收到明确新增需求时才进入计划。
6. 地图、收藏、隐患、预算或房产实勘任务还必须遵守 [submission_commitments.md](./submission_commitments.md)；其中能力未经用户明确授权不得重新列为待决定、排除或 mock。
