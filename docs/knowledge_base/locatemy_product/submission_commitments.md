# 大学提交承诺基线

## 权威性与变更规则

2026-09-17 项目负责人明确授权为一次性大学交付重新审查全部 Feature/shared module，并已确认取消账号数据离线同步、创建队列、照片待上传队列与跨 Feature 强制退出清理机制。下列对应条款不再约束本次精简；后续已确认删除房产跨重启草稿、个人化地点适配度及五项评估偏好；房产回收站／恢复明确保留，风险规则按下文更新。此次授权不修改原始提交稿，也不表示下面全部能力都已批准删除。

本文件记录两份已提交且不可修改的大学作业回顾中，用户确认必须完成的产品功能。它们是当前产品资料中这些功能的**承诺基线**：若与 `placeholder`、`excluded`、待决策项或原型限制冲突，以本文件为准；原型状态仍只描述当前仓库，不能被改写成“已经实现”。

来源为 `map_and_hazard.md`（SHA-256：`73d089986ca43b91e7fa981079562c0f629f8610a188a56caccdd238620ccc90`）和 `budget_and_property.md`（SHA-256：`a44b9e84a2f3d880e26bbde9d20d47f83884e0ed44c86dc07be7f815bedb2c99`）。原始提交稿不纳入本仓库知识库，也不得修改。未来凡涉及地图、收藏、隐患、预算或房产实勘的删改、降级、排除或范围判断，必须先读取本文件；除非用户明确授权，不得删除、弱化或以 mock 替代以下能力。

## 地图、地点与收藏

- `MAP-01`、`MAP-02`：使用可缩放、可拖动的 OpenStreetMap 地图；支持点选、图钉和图层。地点搜索使用 Geoapify Autocomplete/Search，并限于马来西亚；所有选点以马来西亚范围校验拒绝范围外坐标。
- `MAP-03`、`MAP-04`：单点及地点 A/B 比较共享一套全局地点状态；比较阻止同一点，且 A/B 只表示呈现顺序。
- `MAP-05`：收藏地点具有名称、坐标、创建时间和账户归属。Supabase 是权威来源，收藏只在线保存、读取与删除，登录同一账户可读取云端记录；取消本机离线创建队列、私有缓存与前台双向同步。
- 正式云端模型为语义正确的 `user_saved_locations`；旧 `user_saved_regions` 仅在确有历史数据时作一次性迁移或兼容，不能再把坐标伪装为行政区 ID。

## 隐患报告

- `HAZ-01`、`HAZ-02`、`HAZ-04`：保留 flood、crime、traffic、infrastructure、other 五类；可由地图长按或明确入口创建，地图图层、详情和“我的报告”均为真实远端数据。标题去空白后必填，提交显示加载、成功和失败反馈。
- 所有登录用户可读取公开隐患图层；发布后报告的 type、标题、描述、位置和上报时间不可编辑，创建者只能更新自身报告的 `pending/resolved` 处理状态或删除。地图读取可以按可视范围和分页查询，不能因性能理由取消公共图层。隐患不进入官方安全指数。
- 报告状态是创建者可管理的处理状态，仅为 `pending` 或 `resolved`，不使用暗示平台审核的 `verified` 或 `rejected`。项目没有维护者审核、隐藏或删除例外。
- `HAZ-03`：每个登录账户对同一报告至多有一条持久化投票，可选赞成、反对或撤回；计数由投票记录计算，不能由客户端直接改写。

## 生活成本与预算

- `COST-01`：保留地点 CPI 对比、PriceCatcher 行政区商品价格比较、购买力/开销差异展示及 3 天公共缓存。它是完整单点生活成本模型和地点比较中的补充呈现，不能取代后者的数据质量、单位和预算压力口径。
- `COST-02`：2026-09-18 用户明确授权删除不保存的“当前月支出”CPI 等效预算换算器；不再作为交付承诺。
- `COST-03`：预算预案须真实、按账户隔离地新增、读取、选择、重命名、编辑金额和删除；切换后依赖预案的读数立即重算。正式字段以当前生活成本规格为准，并兼容提交稿中的住房、生活、交通金额语义。

## 房产实勘

- `PROP-01`、`PROP-03`、`PROP-04`：房产新增、编辑、档案、详情与至少两份记录的并排对比必须持久化并按账户隔离。看房表单保留名称、地址/地点、价格、排水/防水/湿度/照明评分、平均综合评分、当地水灾线索、备注；不得以启动示例数据替代真实档案。
- 新增或坐标改变时保存统计州、州级安全指数和附近隐患数的风险快照。详情显示档案快照与数据时间，普通编辑、查看和重启不重算；取消手动刷新和自动补算。风险不可用仍允许保存，明确标记不可用；不以旧地点风险冒充新坐标风险。
- `PROP-02`：照片由相机或相册取得，压缩后作为私有 Supabase Storage 文件保存，并以实勘元数据记录说明与封面。每份实勘最多 20 张；照片只在线上传，显示加载、成功和失败反馈，取消离线待传与自动同步。
- `PROP-05`：删除先进入可见回收站，支持恢复与确认后的清空。清空将永久删除当前账户的实勘记录及其 Storage 照片；单张照片删除不进入回收站。

## 落地与验收约束

实现时以相应功能规格、`persistence_matrix.md` 和 `CONTEXT.md` 为数据边界事实源；本文件记录经用户修订后仍保留的用户可见能力。验收以应用页面行为为主，覆盖正确账户记录、云端跨重启保留、网络失败反馈、本地公共缓存、回收站／恢复与风险快照时机；不再验收已删除的预算 JSON、离线队列、待上传或跨模块强制清理证明。
