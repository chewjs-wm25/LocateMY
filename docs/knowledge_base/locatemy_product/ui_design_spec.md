# LocateMY UI 设计规范

## Agent 使用方式

- 本文件保存界面设计约束。功能是否已实现仍以 [capability_catalog.md](./capability_catalog.md) 为准。
- 设计稿描述重开发目标，不表示当前代码或后端已经完成。

## 分析页面精简边界（2026-09-17）

本节记录用户最终确认的界面取舍，是本轮修改的唯一产品事实源。用户要求以其提供的表格为边界，不以此前项目文档补充限制；先前固定快照、删除指标和整体算法替代建议已撤回。适用于首页和单点／A/B 分析，不扩展到业务记录时间。

### 本次实施

- 保留全部分析指标、原有公式与交互。生活成本的最新共同月份 CPI、价格取数、约 3 天公共缓存及行政区／州归一化保持不变；设施的 24 小时缓存也保持不变。缓存过期按原机制失效，不因隐藏时间而继续复用。
- 分析页面不展示结果生成时间、最后查询时间、快照 ID、参照网格版本、逐数据源 URL；取消独立“数据来源”行。OSM 署名和版权链接保留。
- 不展示查询／缓存时间、“数据较旧／可能过期”提示或 TTL 倒计时。内部日期、缓存有效期、来源完整性、分析日期、可比性判断仍保留。首页刷新冷却不是缓存 TTL，本轮保留其交互。
- 技术错误明细（HTTP 状态、异常类型／堆栈、feed URL、内部失败字段）不进入用户页面。保留简短错误／资料不完整／暂不可用状态与重试；刷新失败保留结果的既有行为不变。
- 相同免责声明只保留一处，不重复出现在卡片、摘要和页尾。可将措辞缩短；统计层级、单位、官方观测与估算的区别，以及“已收录设施”的准确含义继续用标题／标签表达。
- 统计年份和价格月份允许调整位置并合并同一期间的重复标签，不强制每张卡重复展示。趋势图年份轴、不同统计年份的区别、CPI 同月计算仍保留；不把源数据月份换成查询时间。
- 房产风险快照采集时间、隐患上报时间、收藏创建时间、预算更新时间和 JSON 导出时间不属于分析页面技术元数据，本轮不改。

### 允许讨论但本次不实施

用户表格允许半径、缺失展示、治安对数步骤、交通分析日期作小幅调整，但没有选定替代值／规则。本次仍保留 2 km／1.5 km、缺失与真实零值的区分、原治安公式和现有交通日期语义，不自行挑选替代方案。

社会经济和基础设施的计算方法在用户表格中标为无法判断，不视为改动授权。生活成本固定快照方案明确撤回；不实施统一固定分析日期、交通距离评分替代、单月篮子、取消 ICI／收入位置／权重或四类存储能力。

实现时按功能原有规则计算和管理数据，仅减少呈现噪声。界面规则引用本节；公式和数据质量仍由各功能事实源定义。本轮文档更新不代表代码或验收已完成。

## 产品体验目标

LocateMY 帮助用户完成一条清晰的决策链：先理解全国搬家时机，再选择地点，随后查看地点分析，最后保存候选地点、预算、隐患报告与房产实勘。界面优先回答“现在是否适合搬”和“这个地点是否适合我”，不把原始数据量当作信息价值。

## 信息架构

```text
认证
├─ 登录
└─ 注册

主应用
├─ 首页
│  ├─ 地点搜索 → 地图
│  ├─ 已保存地点 → 地图定位
│  └─ 全国搬家时机概览
├─ 地图
│  ├─ 单点探索
│  ├─ 两地对比 → 地点比较
│  ├─ 已保存地点
│  ├─ 隐患上报
│  └─ 地区分析
│     ├─ 生活成本
│     ├─ 治安与犯罪
│     ├─ 社会经济
│     ├─ 基础设施
│     ├─ 周边设施
│     └─ 公共交通
└─ 账户
   ├─ 房产实勘档案 → 新增/详情/编辑/对比
   ├─ 我的隐患报告 → 状态标记/地图定位/删除
   ├─ 语言
   └─ 退出登录
```

一级导航只有首页和地图。账户是从顶栏进入的任务页，不增加第三个一级 Tab。子页面统一使用返回导航。

## 视觉方向

风格为“可信赖的公共数据工具 + 轻量生活规划”，避免银行式压迫感和社交应用式装饰。

| 令牌 | 值 | 用途 |
| --- | --- | --- |
| Primary | `#155EEF` | 主要按钮、选中 Tab、地图选点 |
| Primary Soft | `#EAF2FF` | 首页探索卡、选中背景 |
| Success | `#16865C` | 有利、良好、完成 |
| Warning | `#B76E00` | 观望、参考值、部分缺失 |
| Danger | `#C9362B` | 高风险、失败、删除 |
| Ink | `#172033` | 标题与主要数值 |
| Muted | `#667085` | 日期、来源、辅助文字 |
| Surface | `#FFFFFF` | 卡片和底部面板 |
| Canvas | `#F6F8FB` | 页面背景 |
| Border | `#D9E0EA` | 输入框、分隔线、非选中控件 |

- 中文使用 Noto Sans SC，英文使用 Inter；系统字体不可用时使用平台默认无衬线字体。
- 页面标题 24sp/700，区块标题 18sp/700，正文 15–16sp，辅助文字不低于 13sp。
- 采用 8pt 间距系统；页面边距 16，卡片内边距 16，卡片圆角 16，按钮圆角 12。
- 主要操作高度至少 48，图标点击区域至少 44×44。
- 数据趋势、风险和状态必须同时使用文字或图标，不能只靠颜色。

## 核心组件

### 顶栏

首页和地图显示品牌、刷新/语言/账户等上下文操作。分析页使用返回、页面标题与最多一个主要操作。避免同一顶栏同时出现超过三个图标。

### 卡片

卡片只承载一个判断。主要数值必须同时带名称、单位和状态。卡片不可只显示孤立分数；0 不能代替缺失数据。

### 地图

- 搜索与模式切换固定在地图上方。
- 地图快捷按钮沿右侧排列，并为屏幕阅读器提供文字名称。
- 单点选择使用一个主色 Marker；对比使用 A/B 两个可区分 Marker。
- 当前地点详情使用可折叠的底部卡片；地区分析使用可拖动底部面板。
- 上报隐患使用独立高可见按钮，不与清除位置共享图标。

### 表单

标签始终显示在输入框外；错误紧贴字段。提交时禁用重复提交并显示进行中状态。失败时保留用户输入。危险操作必须确认。

### 图表

图表只展示页面核心趋势。图例、单位和统计口径必须可见；没有触摸明细时不绘制误导性的交互提示。估算结果明确标注“估算 / Estimated”。

### 空、错、加载状态

- 初次加载用骨架屏或局部加载，不用整页无限转圈。
- 单一数据源失败时保留其他成功卡片，并在失败卡片内重试。
- 空结果说明是“范围内没有记录”还是“资料尚未提供”。

## 地点契约

- `selectedLocation` 是六类单点分析页的唯一分析目标；生活成本单点页不得读取第二个地点。
- 两地比较使用 `locationA` 与 `locationB`。缺少任一地点时停留在补全地点状态，不静默套用固定城市；两处相同必须阻止比较并给出字段级提示。
- 单点与对比模式状态分离；切换模式不自动删除另一模式的内容。
- 对比页提供交换按钮；交换只改变地点 A/B 的呈现顺序，不表达搬迁方向。
- 公共交通页不提供“在主地图中查看”；站点分布图只在本页显示局部范围，不更新主地图选点。
- 周边设施和公共交通的页面选择器只改变真实分析目标，不显示无效的两地控件。
- 地区统计显示所属行政区；附近服务显示固定半径。指标标明其口径与必要的估算／不可用状态；技术元数据展示遵循本文件“分析页面精简边界”。

## 页面决策

### 首页

- 首页唯一高强调操作是“探索地图”。
- 全国搬家时机卡显示 0–100 分、状态和最多三条原因。
- 成本、就业和经济动能为主要分项；家庭收入中位数作为更多宏观指标保留，不参与搬家时机评分。
- 首页不展示 OPR 利率。
- 收藏预览最多两项。地点适配分与全国搬家时机分使用不同名称；没有完成地区分析时显示“未分析”。

### 地图和分析入口

- 单点模式下，六类分析必须在有合法分析地点后才能进入；地区分析底部面板显示该分析目标。
- 两地模式下，两个地点有效后显示“查看地点比较”，进入六类分析的比较总览；移除只比较生活成本的主入口。
- 隐患刷新、收藏、图层、清除和分析使用独立文字提示；图标顺序不承担唯一含义。
- 地点详情折叠态显示地点和操作；展开态显示安全、成本、日常便利、公共交通可达性和基础设施五项摘要。
- 摘要使用原生、可解释的单位：安全指数、相对成本、2 km 生活类别覆盖及最近关键设施距离、1.5 km 站点与步行可达提示、基础设施状态与最低或缺失分项。社会经济不出现在地图摘要。
- 用户隐患报告不进入地点详情；它保留在独立的隐患图层中，不进入官方安全指数。
- 生活篮子在最近 12 个月内可用月份少于 6 个月或平均覆盖率低于 80% 时，标明部分篮子资料并将预算压力标为不可计算。
- 地点详情不生成优势／留意点文字，只显示数据。操作限定为收藏、查看完整分析和发起比较；发起比较时让用户选择当前地点是地点 A 还是地点 B。

### 生活成本

- 单点报告展示本地价格、统一生活篮子的估算月支出及相对于固定基准的生活成本指数；不显示另一地点、迁居方向或地点间涨跌。
- 有当前评估预案时额外展示预算压力；没有预案时保留成本报告，并说明预算压力尚不可计算及设置入口。默认金额和默认预算都不能替代预案。
- 地点比较的生活成本详情以相同口径并列 A/B 的单点结果；资料可比时显示差异，并可展示同名商品价格对照。
- 预算预案的名称、统一生活篮子调整、住房支出、交通支出、月净收入和家庭月度总收入在同一个编辑流程中保存；两种收入的用途与缺失状态分开说明。
- 切换预案后立即重算预算压力。
- 当前评估预案由账户保存并可在预算流程中切换；它是地点详情显示预算压力的必要输入。
- 住房或交通明确为 RM 0 视为已填写，未填写则显示相应不可用状态。
- “查看商家”（`COST-04`）归类为 `excluded`，设计稿不显示该按钮。

### 地点比较

- 总览以地点 A/B 并列六类主读数：生活成本指数与月支出、安全指数、家庭收入中位数与基尼系数、基础设施综合覆盖指数、2 km 设施覆盖类别数与设施总数、交通连通性与 1.5 km 站点数。
- 总览卡进入对应类别的两地分项详情；不得把异质读数压缩成一个客观总分。
- 只有两边资料可用且统计口径一致时才显示差异。其余卡片保留可用的一侧，并简短说明资料缺失或口径不可比的原因；日期标签与元数据展示遵循本文件“分析页面精简边界”。

### 治安与犯罪

- 页面是单点分析，顶部不显示无效两地选择器。
- 犯罪类别筛选只影响趋势图，因此在控件下明确说明作用域。
- 治安页不承载专题地图；“查看主地图”只导航至当前地点。隐患类型筛选和隐患图层由独立隐患功能负责，不进入安全指数。
- 治安页不展示最近房产、逐行房产详情或 `and N more properties...`；Portfolio 只进入房产档案，Add Property 只进入新增房产表单。

### 社会经济

- 页面是单点分析。
- 官方收入、排名和基尼与模型估算的 B40/M40/T20、分布和个体百分位在视觉上分组，并持续显示“估算”。
- 用户收入位置使用家庭月度总收入，与所属州最新完整年份的 `hies_state_percentile` `variable = median` 数据做百分位插值；低于 P1、高于 P100 和缺失状态分别明确显示。
- 不把用户输入结果声明为官方阶层判定。

### 基础设施

- 分项统一显示供水、供电、医疗、教育和公共交通。
- 当前可调优先级为医疗、教育和交通便利；“商业便利性”重命名为“交通便利性”，与真实分项一致。
- ICI 权重按账户保存为全局权重，未设置时使用中性默认值 5；它只影响本页单点 ICI 综合结果，不改变地点摘要与 A/B 使用的中性 ICI。
- 缺失数据使用 `—`，同时列出缺少的资料项。

### 周边设施

- 范围固定显示为 2 公里，五类均可见；页面显示覆盖数量，不生成综合指数。
- 每类最多展示三条已收录设施。设施详情、展开和路线（`FAC-02`）归类为 `excluded`，因此不显示装饰性箭头或“查看更多”。

### 公共交通

- 范围统一为 1.5 公里。
- 原“热力图”更名为“站点分布图”，展示分析中心、范围圆和站点 Marker。
- 列表与地图保持选中联动；不增加路线、班次或运营时间。
- 有站点但分析日期无有效路线时显示“有站点，但分析日期没有有效服务路线”；部分 feed 获取或解析失败时，按公共交通事实源计算并显示“部分交通分”及不完整提示；无有效路线仍不可评分，不以 0 分替代缺失。

### 房产实勘

- 保留档案、新增、详情、编辑和 2–3 项对比。
- 不提供跨重启草稿恢复；风险快照保存在档案，仅新增／坐标变化时重算，查询失败仍允许保存并标记不可用。详情无手动刷新或自动补算。
- 地点可从已保存地点选择，也可从地图返回式选点，不退出并丢失表单。
- 新增与编辑页提供相机和相册两个照片入口，并展示 `已添加 n/20`。达到上限后，入口说明需引导用户先删除已有照片。
- 照片以可排序缩略图呈现；每张可编辑自由文字说明、删除，且可设为封面。封面要有清晰标识；删除封面后即时回退到最早添加的剩余照片。没有照片的实勘使用默认占位。
- 档案卡片与房产对比各只显示封面；详情页展示完整照片库和每张照片说明。照片不提供分享、导出、EXIF 信息展示、标签或圈选标注。
- 照片只在线上传，加载、成功和失败均有明确反馈；失败可在当前表单重新尝试，不建立离线待上传或后台自动重试队列。单张照片删除在线完成；离线时说明联网后重试。
- 照片入口和错误状态需同时满足真实持久化、账号隔离、失败恢复与权限处理。
- 删除默认采用确认后的软删除语义；[大学提交承诺基线](./submission_commitments.md)要求提供可见回收站、恢复和确认后的永久清空，因此正式 UI 必须提供相应入口。

### 隐患

- 保留五种类型、标题、描述和位置。
- 标题必填且去除首尾空白；提交有加载、成功和失败反馈。
- 历史 UI 稿不展示投票；但提交承诺基线已确认投票必须实现为每账户每报告一条、可撤回的持久化赞成/反对记录。正式设计不得因历史 UI 未展示而删除该能力，并须以隐患功能事实源和 schema/RLS 契约补齐状态、计数及失败反馈。
- 我的隐患报告支持刷新、创建者自己的 `pending/resolved` 状态标记、地图定位和确认删除。创建提交前可修正类型、标题、描述和位置；成功发布后这些内容及上报时间不可编辑。状态不表示平台审核，界面不提供 `verified`/`rejected`、隐藏或维护者操作。

### 账户

- 只显示真实邮箱、房产实勘、我的隐患报告、当前评估预案、语言和退出登录；验证状态与五项评估偏好删除。
- 未实现的搬迁历史、默认地点、保存的对比、评论与点赞统计全部移除。
- 退出后回到登录页，关闭普通业务页面；换账号后按当前用户读取记录，不等待跨模块清理或删除预算导出文件。

## 双语与内容规则

本节是全项目中英文实施的统一产品规范。各功能引用本节，仅补充自身范围，不另设默认语言、保存方式或翻译例外。依据：项目负责人 2026-09-16 要求为 Authentication 实施中英文支持并统一规范；既有 NAV-03 和本机语言偏好决策继续有效。

- 支持简体中文与英文；首次启动没有有效偏好时使用中文，不跟随设备语言自动改变选择。不支持或损坏的偏好回退中文。
- 每次只显示一种语言。语言入口可在未登录时使用，在登录、注册、会话恢复、会话不可用、已登录与退出失败等状态中均可操作；入口的无障碍说明也随语言切换。
- 切换立即更新当前页面、已有校验错误、成功/失败反馈、对话框及系统组件文案，不重新提交操作、不改变认证状态、不清空正在填写的表单。
- 偏好保存到本机键值存储，跨重启保留，不绑定账号，退出或切换账号不清除。保存失败时保留当前界面的语言选择并显示当前语言的失败提示；不得声称已持久保存。
- 中英文覆盖完全相同的功能、页面与状态，包括字段标签、提示、主要和次要操作、加载、空状态、校验、网络错误、成功提示、确认对话框、隐私与数据边界说明。新增或修改文案时两种语言必须一起更新，不允许未翻译内容静默混入。
- 品牌名 `LocateMY`、货币 `RM`、官方缩写和必要技术标识可保持不翻译。用户输入的邮箱、用户名和业务内容原样展示，不自动翻译。
- 中文使用“地点”“房产实勘”“隐患”；英文分别使用 “location”, “property inspection”, “hazard”。认证中“登录”为 “Sign in”，“创建账户”为 “Create account”，“退出”为 “Sign out”，不再展示邮箱验证状态。
- 后端错误通过稳定的业务结果映射到当前语言的用户提示，不直接展示服务端原始错误；未识别结果使用当前语言的通用错误提示。
- 中文日期使用本地化年月日，英文按设备地区格式显示；同一页面不要混用格式。动态复数、数字和日期使用本地化规则，不直接拼接英文 `s` 或固定日期文本。
- 保留的估算、错误、必要缓存状态与非官方评分说明随语言切换；不为已取消的来源／时间／较旧提示新增 UI。
- 两种语言均满足小屏和 200% 动态字体要求，允许换行、页面滚动与卡片增高，不能截断主要操作、字段标签或错误提示。
- 功能双语验收必须覆盖两种语言的正常流程、校验与失败状态；同时确认切换保留输入和业务状态、重启恢复偏好、退出保留偏好，以及小屏大字体可操作。局部功能完成不代表全应用翻译覆盖完成。


## 响应式与可访问性

- 设计基准宽度 360–430dp；小屏改为单列，不缩小文字来塞入两列。
- 动态字体 200% 时，主要操作、表单标签和数值不可截断；卡片允许增高。
- 地图、图表和评分提供文字摘要；屏幕阅读器读取时先读结论，再读数值与日期。
- 正文与背景对比度至少 4.5:1，大字号至少 3:1。
- 动画尊重“减少动态效果”；加载、切页和图表动画不应阻碍操作。
- 键盘可见时表单提交按钮仍可到达，错误出现后焦点移动到第一个无效字段。

## 不进入当前 UI 的内容

以下能力在 2026-09-13 产品范围基线中归类为 `excluded`，不进入设计波次。

- Magic Link、游客模式、忘记密码、注销账户。
- 独立气候/水灾页、GPS 当前定位、离线地图、路线规划。
- 商家下钻（`COST-04`）、设施详情与路线（`FAC-02`）、公共交通路线/班次、真正 GIS 热力图。
- 搬迁评估历史（`ACCOUNT-03`）、默认地点（`ACCOUNT-04`）、保存的地点对比（`ACCOUNT-05`）、评论与点赞统计（`ACCOUNT-06`）。
- 隐患的审核进度（如 `verified`/`rejected`）、保存房产对比结果。

这些能力只有在产品明确新增需求并补齐数据、权限和持久化契约后，才可加入 UI。隐患投票和房产回收站不在本清单内，它们由[大学提交承诺基线](./submission_commitments.md)锁定为 `required`。

## 验收清单

- 中文与英文覆盖同一页面、状态和错误信息。
- 登录前无法进入主应用；退出后无法看到前一账号私有内容。
- 首页/地图 Tab 保持一致，所有分析页均可返回原任务上下文。
- 所有分析结果明确地点、单位和官方/估算边界；统计日期允许集中表达，按“分析页面精简边界”验收。
- 页面没有无回调按钮、装饰性箭头或假数据统计。
- 缺失、空结果、离线、超时和提交失败均有可恢复路径。
- 颜色不是风险、趋势或选中状态的唯一表达方式。
