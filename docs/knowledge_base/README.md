# 项目知识库

知识库只保存未来任务难以快速重建、且会改变 LocateMY 产品理解或决策的长期事实。产品知识从 [locatemy_product/README.md](./locatemy_product/README.md) 进入；按任务只读取相关文件。

## 收录边界（写入前必读）

一项内容只有同时满足以下条件才可写入：

- 已由用户确认、实际验证或可追溯来源支持；
- 对未来多个任务仍有用；
- 影响产品范围、用户可见行为、领域语义、数据边界或已采纳的产品决策；
- 不能从单个代码、配置或现有文档中快速可靠地重建。

以下内容不入库：

- 任务过程、工作总结、命令或测试输出、临时排障记录；
- 实现架构、代码细节、文件清单和可由仓库直接回答的信息；
- 未确认的方案、推测、偏好、待办和研究素材；
- 外部数据目录、原始数据、整份外部资料或其批量元数据快照；
- 已有事实的改写、索引副本和其他生成物。

写入时优先修订现有事实源，删除被新结论取代的内容。只有没有合理归属时才新建文件，并只保留结论、必要语境与最少来源。

## 事实优先级

冲突时依次采用：当前用户明确指示、最新验证结果、当前产品资料。历史资料只用于解释，不进入当前事实源。
