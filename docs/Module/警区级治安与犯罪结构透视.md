# 警区级治安与犯罪结构透视

## 1. 模块简介与定位
- **模块名称**：警区级治安与犯罪结构透视 (Police District Crime Structure Perspective)
- **功能描述**：基于皇家警察（PDRM）提供的警区级定罪数据，以 Flutter 图表化方式展示目标区域的年化犯罪率、暴力与财产犯罪比例及其历史演变趋势。同时引入**社区微观“排雷”众包地图**，借助用户生成内容 (UGC) 与 Supabase Realtime 实时数据流，填补官方大粒度数据的时效性与微观颗粒度空白。

## 2. 决策维度剖析与用户价值
- **公共安全与环境风险维度（治安板块）**：
  - 警区级的治安状况（包括暴力犯罪与财产犯罪的具体定罪数据）是衡量社区安全的重要指标。
  - 用户可清晰了解目标社区的治安风险等级、高发案由分类，为家庭居住选址提供直接的安全参考。
  - **社区协同排雷与互助验证**：宏观警区定罪数据无法反映社区夜间路灯故障、偷窃频发小巷或特定弯道易积水等微观隐患。众包地图允许真实居民与考察者实时标记与验证隐患，显著提升安全决策的时效度。

## 3. 核心数据源与 API 规范

### 3.1 警区级治安数据 (`crime_district`)
- **数据机构**：皇家警察 (PDRM) / OpenDOSM / Data.gov.my
- **数据内容**：记录警区级（Police District）实际定罪案件数，按暴力犯罪（如 assault）和财产犯罪（如 property）分类。
- **API 端点**：`GET https://api.data.gov.my/data-catalogue?id=crime_district`
- **关键提取字段**：`district`, `category` (assault/property), `type`, `crimes`
- **更新机制**：按年度更新。
- **费用与限制**：100% 免费公开 API，无需 API Key 或绑定信用卡。

## 4. 空间边界对齐与 Supabase PostGIS 解决方案

### 4.1 空间粒度不一致的技术挑战
- **差异问题**：警区（Police District）划分与行政县（Administrative District）并不完全重合，且官方数据统计的是法院已定罪案件。
- **前端呈现**：在 Flutter UI 界面中通过信息提示 Banner（`Tooltip` / `Card`）进行明确的空间范围与统计口径说明。

### 4.2 Geospatial Crosswalk 空间映射实现 (Supabase PostGIS)
- **Supabase PostGIS 免费扩展**：在 Supabase 控制台执行 `CREATE EXTENSION IF NOT EXISTS postgis;`（Supabase Free Tier 完全免费支持）。
- **空间映射函数 (PostgreSQL RPC)**：利用 PostGIS 的 `ST_Contains` 与 `ST_SetSRID(ST_Point(lng, lat), 4326)`，将用户在 Flutter 地图上选择的经纬度自动匹配至警区多边形：

```sql
-- Supabase 免费 Postgres 存储过程：坐标反查所属警区
CREATE OR REPLACE FUNCTION match_police_district(lng double precision, lat double precision)
RETURNS TABLE (police_district_id text, district_name text, state text) AS $$
BEGIN
  RETURN QUERY
  SELECT p.id, p.name, p.state
  FROM police_districts_boundary p
  WHERE ST_Contains(p.geom, ST_SetSRID(ST_Point(lng, lat), 4326))
  LIMIT 1;
END;
$$ LANGUAGE plpgsql SECURITY DEFINER;
```

## 5. 交互式扩展模块：社区微观“排雷”众包地图 (Flutter + Supabase)

### 5.1 业务逻辑与系统结合点
在“空间选址与速览比对页”及“警区级治安透视”地图图层中，叠加 UGC 众包排雷图层。用户可在 Flutter 交互式地图（`flutter_map`）上长按打点，提交治安死角、照明故障、积水点或物价异常的排雷事件，并上传实拍照片。其他用户可对其进行点赞证实 (Upvote) 或质疑 (Downvote)，所有变动通过 Supabase Realtime 实时推送到多端。

### 5.2 技术架构与 0 成本保障
* **前端**：Flutter + `flutter_map` + `supabase_flutter` + `image_picker`。
* **后端**：Supabase Free Tier（PostgreSQL + PostGIS 空间索引 + Supabase Auth 鉴权 + 免费 1GB Supabase Storage + Realtime 广播）。
* **零成本合规**：无需绑定任何信用卡，PostGIS、Storage、Realtime 与 Auth 均在永久免费额度内。

### 5.3 数据库 Schema 与 RLS 安全策略设计

#### 数据表 1：`crowdsourced_hazards` (排雷事件表)

```sql
-- 启用 UUID 与 PostGIS 扩展
CREATE EXTENSION IF NOT EXISTS "uuid-ossp";
CREATE EXTENSION IF NOT EXISTS postgis;

CREATE TYPE hazard_category AS ENUM (
  'SAFETY_DEADZONE', 
  'FLOOD_SPOT', 
  'POOR_LIGHTING', 
  'PRICE_ANOMALY', 
  'OTHER'
);

CREATE TYPE hazard_status AS ENUM (
  'ACTIVE', 
  'RESOLVED', 
  'EXPIRED'
);

CREATE TABLE crowdsourced_hazards (
  hazard_id UUID PRIMARY KEY DEFAULT uuid_generate_v4(),
  user_id UUID NOT NULL REFERENCES auth.users(id) ON DELETE CASCADE,
  hazard_type hazard_category NOT NULL,
  title VARCHAR(128) NOT NULL,
  description TEXT,
  latitude DOUBLE PRECISION NOT NULL,
  longitude DOUBLE PRECISION NOT NULL,
  location_geom GEOMETRY(Point, 4326),
  poskod VARCHAR(10),
  police_district_id VARCHAR(64),
  upvotes_count INT NOT NULL DEFAULT 0,
  downvotes_count INT NOT NULL DEFAULT 0,
  status hazard_status NOT NULL DEFAULT 'ACTIVE',
  photo_urls TEXT[] DEFAULT ARRAY[]::TEXT[],
  created_at TIMESTAMPTZ NOT NULL DEFAULT NOW(),
  updated_at TIMESTAMPTZ NOT NULL DEFAULT NOW()
);

-- 空间索引加速矩形视窗查询
CREATE INDEX idx_crowdsourced_hazards_geom ON crowdsourced_hazards USING GIST(location_geom);

-- 触发器：自动填充 location_geom
CREATE OR REPLACE FUNCTION set_hazard_geom()
RETURNS TRIGGER AS $$
BEGIN
  NEW.location_geom := ST_SetSRID(ST_Point(NEW.longitude, NEW.latitude), 4326);
  NEW.updated_at := NOW();
  RETURN NEW;
END;
$$ LANGUAGE plpgsql;

CREATE TRIGGER trg_set_hazard_geom
BEFORE INSERT OR UPDATE ON crowdsourced_hazards
FOR EACH ROW EXECUTE FUNCTION set_hazard_geom();
```

#### 数据表 2：`hazard_feedbacks` (用户反馈与协同验证表)

```sql
CREATE TYPE vote_action AS ENUM ('UPVOTE', 'DOWNVOTE');

CREATE TABLE hazard_feedbacks (
  feedback_id UUID PRIMARY KEY DEFAULT uuid_generate_v4(),
  hazard_id UUID NOT NULL REFERENCES crowdsourced_hazards(hazard_id) ON DELETE CASCADE,
  user_id UUID NOT NULL REFERENCES auth.users(id) ON DELETE CASCADE,
  vote_type vote_action NOT NULL,
  comment TEXT,
  created_at TIMESTAMPTZ NOT NULL DEFAULT NOW(),
  UNIQUE(hazard_id, user_id) -- 限制每位用户对同一排雷事件只能投一次票
);
```

#### Supabase 行级安全策略 (Row Level Security - RLS)

```sql
ALTER TABLE crowdsourced_hazards ENABLE ROW LEVEL SECURITY;
ALTER TABLE hazard_feedbacks ENABLE ROW LEVEL SECURITY;

-- 任何人（包含游客）均可读取所有公开排雷标记
CREATE POLICY "Public Read Hazards" ON crowdsourced_hazards
  FOR SELECT USING (status != 'EXPIRED');

-- 仅登录用户可创建新排雷记录
CREATE POLICY "Authenticated Insert Hazards" ON crowdsourced_hazards
  FOR INSERT WITH CHECK (auth.uid() = user_id);

-- 仅原作者可更新或解决自己的排雷记录
CREATE POLICY "Owner Update Hazards" ON crowdsourced_hazards
  FOR UPDATE USING (auth.uid() = user_id);

-- 仅原作者可删除排雷记录
CREATE POLICY "Owner Delete Hazards" ON crowdsourced_hazards
  FOR DELETE USING (auth.uid() = user_id);

-- 投票表的 RLS 策略
CREATE POLICY "Public Read Feedbacks" ON hazard_feedbacks
  FOR SELECT USING (true);

CREATE POLICY "Authenticated Insert Feedbacks" ON hazard_feedbacks
  FOR INSERT WITH CHECK (auth.uid() = user_id);

CREATE POLICY "Owner Update Feedbacks" ON hazard_feedbacks
  FOR UPDATE USING (auth.uid() = user_id);
```

#### 空间视窗检索 RPC 函数 (PostGIS Bounding Box)

```sql
-- 依据地图视窗经纬度范围高效获取排雷标记
CREATE OR REPLACE FUNCTION get_hazards_in_bounds(
  min_lng DOUBLE PRECISION,
  min_lat DOUBLE PRECISION,
  max_lng DOUBLE PRECISION,
  max_lat DOUBLE PRECISION
)
RETURNS SETOF crowdsourced_hazards AS $$
BEGIN
  RETURN QUERY
  SELECT *
  FROM crowdsourced_hazards
  WHERE location_geom && ST_MakeEnvelope(min_lng, min_lat, max_lng, max_lat, 4326)
    AND status != 'EXPIRED';
END;
$$ LANGUAGE plpgsql STABLE;
```

### 5.4 Flutter 客户端集成与 CRUD 操作规范

```dart
import 'package:flutter/material.dart';
import 'package:supabase_flutter/supabase_flutter.dart';
import 'package:image_picker/image_picker.dart';

class HazardService {
  final _supabase = Supabase.instance.client;

  // 1. Create: 上传实拍照片并发布排雷标记
  Future<void> createHazard({
    required String title,
    required String description,
    required String hazardType,
    required double lat,
    required double lng,
    required List<XFile> images,
  }) async {
    final user = _supabase.auth.currentUser;
    if (user == null) throw Exception("请先登录后发布排雷");

    List<String> uploadedUrls = [];
    for (var img in images) {
      final bytes = await img.readAsBytes();
      final fileExt = img.name.split('.').last;
      final fileName = '${user.id}/${DateTime.now().millisecondsSinceEpoch}.$fileExt';
      
      // 上传至 Supabase 免费 Storage Bucket
      await _supabase.storage.from('hazard_photos').uploadBinary(
        fileName,
        bytes,
        fileOptions: FileOptions(contentType: 'image/$fileExt'),
      );
      final publicUrl = _supabase.storage.from('hazard_photos').getPublicUrl(fileName);
      uploadedUrls.add(publicUrl);
    }

    // 写入 PostgreSQL
    await _supabase.from('crowdsourced_hazards').insert({
      'user_id': user.id,
      'title': title,
      'description': description,
      'hazard_type': hazardType,
      'latitude': lat,
      'longitude': lng,
      'photo_urls': uploadedUrls,
    });
  }

  // 2. Read: 结合地图视窗拉取排雷标记
  Future<List<Map<String, dynamic>>> fetchHazardsInBounds({
    required double minLng,
    required double minLat,
    required double maxLng,
    required double maxLat,
  }) async {
    final response = await _supabase.rpc('get_hazards_in_bounds', params: {
      'min_lng': minLng,
      'min_lat': minLat,
      'max_lng': maxLng,
      'max_lat': maxLat,
    });
    return List<Map<String, dynamic>>.from(response);
  }

  // 3. Realtime Stream: 实时监听排雷变更
  Stream<List<Map<String, dynamic>>> streamActiveHazards() {
    return _supabase
        .from('crowdsourced_hazards')
        .stream(primaryKey: ['hazard_id'])
        .eq('status', 'ACTIVE');
  }

  // 4. Update: 点赞 / 踩协同验证 (原子 RPC 更新)
  Future<void> voteHazard(String hazardId, String voteType) async {
    final user = _supabase.auth.currentUser;
    if (user == null) throw Exception("请先登录后再验证");

    await _supabase.from('hazard_feedbacks').upsert({
      'hazard_id': hazardId,
      'user_id': user.id,
      'vote_type': voteType,
    });
  }

  // 5. Delete: 原作者撤回标记
  Future<void> deleteHazard(String hazardId) async {
    await _supabase.from('crowdsourced_hazards').delete().eq('hazard_id', hazardId);
  }
}
```
