# 视图层：生活开销组件

## 描述
用于比较马来西亚两个地区之间生活开销的 UI。

## 关键 UI 元素
- **地点选择器**：出发地和目的地县的下拉菜单或搜索框。
- **预算输入**：当前月度支出的输入字段。
- **对比摘要**：购买力变化的文本总结。

## 数据可视化
- **对比直方图**：
    - **用途**：对比各类别（食品、住房、公用事业、交通、其他）在“搬家前”与“搬家后”的开销。
    - **数据源**：计算得出的差异化指数。
- **开销饼状图**：
    - **用途**：目的地预估月度支出的各项细分。
    - **数据源**：根据目的地 CPI 调整后的预算。

## 交互
- 用户调整各类别权重的滑块（影响综合评分）。
- 点击直方图中的类别可查看详细的单品价格差异（PriceCatcher 数据）。
