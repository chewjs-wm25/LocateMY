# 视图层：生活开销分析 (Cost of Living Analysis)

## 重新设计目标
从传统的“数值展示”转向“生活方式平移 (Lifestyle Translation)”，帮助用户直观理解在目标城市维持现有生活水平的财务需求。

## 关键 UI 核心模块

### 1. 生活方式平移总结 (Lifestyle Translation Hero)
- **核心逻辑**：基于 OpenDOSM 的 CPI (消费者价格指数) 计算。
- **展示内容**：
    - **购买力变化百分比**：如 "+15.2% 购买力提升"。
    - **等效预算对比**：显示“在 [目标地] 维持 [当前地] RM 5,000 的生活水平仅需 RM 4,250”。
    - **财务建议标签**：如“生活质量显著提升”或“需注意租金上涨”。

### 2. 交互式预算编辑器 (Interactive Budget Editor)
- **输入端**：允许用户输入当前在原住址的真实月度支出（住房、食品、交通、公用事业）。
- **预测端**：实时根据目标地的 CPI 权重自动计算建议预算，并支持手动调校。

### 3. 微观物价透视器 (Micro-Price Insight)
- **地理围栏触发**：根据用户选择的居住点（POSKOD），自动筛选方圆 5 公里内的商家。
- **实地比价表**：使用 `PriceCatcher` 数据，展示 5-8 种高频民生物资（鸡蛋、肉鸡、燃油、面包等）在两地 5km 内的真实成交均价对比。
- **来源透明度**：标注数据采集的超市或巴刹名称，增强可信度。

### 4. 情景沙盒 (Scenario Sandbox)
- **预案切换**：支持“独居极简”、“家庭育儿”、“买房 vs 租房”等多种生活情景的横向比对。
- **持久化**：通过 Supabase 存储多个预案，方便用户反复权衡。

## 数据可视化
- **雷达图 (Radar Chart)**：对比五大维度的开销指数。
- **并排柱状图 (Side-by-side Bar Chart)**：直观对比当前 vs 目标地的预算分布。
- **盈余仪表盘**：动态展示搬家后每月的预计结余增减。

## 交互设计
- **滑动调校**：用户调整某一类别预算时，其他类别根据比例自动平衡。
- **点击下钻 (Drill-down)**：点击“食品”类别，弹出微观物价透视列表。
