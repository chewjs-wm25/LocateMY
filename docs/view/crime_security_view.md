# 视图层：治安与犯罪组件

## 描述
在警区（Police District）级别可视化犯罪结构和安全趋势。

## 关键 UI 元素
- **地区地图**：高亮显示的警区边界。
- **安全评级**：数字评分或徽章（安全/中等/警示）。
- **类别筛选**：在“暴力犯罪”和“财产犯罪”之间切换。

## 数据可视化
- **历史折线图**：
    - **用途**：展示过去 5 年的犯罪率趋势。
    - **数据源**：皇家警察 (PDRM) `crime_district` 年度统计数据。
- **犯罪类型饼状图**：
    - **用途**：犯罪类别的细分（如抢劫、袭击、盗窃）。
    - **数据源**：`crime_district` 类别数据。

## 交互
- 在地图上缩放以查看更高分辨率的警区边界。
- 悬停或点击折线图中的数据点以查看确切的案件数量。
