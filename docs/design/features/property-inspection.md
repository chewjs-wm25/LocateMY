## 表单与在线记录

保留名称／地址／合法坐标／价格／四项 1–5 现场评分／水灾迹象／备注，以及四评分平均。
新增和编辑只在线保存 Supabase；成功后档案／详情读取云端真实记录，不用启动示例或 mock。
当前页输入在地图返回式选点期间保留：Navigator.push 返回合法地点，再填入仍存活的表单。
不保存跨重启草稿、草稿照片或后台同步队列。保存失败保留当前页输入与普通重试反馈。
唯一公开入口 `lib/features/property_inspection/property_inspection.dart`；页面明确实勘 id／坐标参数，
具名服务消费 Geo、州级安全业务与 HazardRiskCounter，不依赖 Shell／AccountScope／Privacy。
实际公开声明、照片平台依赖与验收分配已固定；实现及证据见本次验收报告。

## 风险快照请求时机

| 操作 | 是否请求风险 | 保存与呈现 |
| --- | --- | --- |
| 新增实勘 | 是，合法当前坐标 | 成功保存完整组；失败仍保存实勘并标 unavailable |
| 实际改变经纬度 | 是，新坐标 | 成功整体替换；失败清除可用旧组并标 unavailable |
| 只改名称、评分、备注、价格或地址文字 | 否 | 保留原快照及采集时间 |
| 地图往返但返回相同坐标 | 否（编辑时） | 不以对象身份或名称差异触发重算 |
| 查看详情、打开档案、重启 | 否 | 读取持久化快照，不自动补算 |

完整组要求同一坐标的州级安全结果和 pending 隐患计数完整可用。
资料缺失／partial／失败仍可提交实勘；不能补零／假数据，不能让旧坐标快照冒充新地点。
保留来源年份、模型／边界、半径、采集时间与可用性；字段唯一见 Schema Catalog。
无手动刷新或自动补算入口。按新坐标查询后若表单又换点，旧请求不得写入该新点。

## 真实照片与部分失败

相机／相册取得真实静态照片、压缩后在线上传，每份最多 20 张；不更改相册原图。
实勘创建成功后才分配正式 photo／Storage 路径；元数据说明可空、一张封面，其余按添加时间排序。
删除封面后以最早剩余照片替代，无照片显示占位；档案／对比显示封面，详情显示照片库。
Storage／元数据各操作只在真实完成后显示成功，部分失败反馈具体未完成项，用户可当前页在线重试。
保留实际云端对象 path 供业务删除重试，不能建立本机持久化上传队列／后台重放／独立恢复模块。
文件归属与访问按父实勘 owner 限制；相机权限拒绝、上传失败和不支持格式有普通反馈。

## 回收站、恢复与永久清空

删除先设置 deleted_at，档案隐藏且可见回收站保留记录和照片；恢复清除此字段，照片重新可读。
取消永久清空无副作用，退出不清空回收站，也不删除云端照片。
确认永久清空后逐份处理：列出照片 path → 删除 Storage 文件 → 删除照片元数据 → 删除实勘。
Storage 部分失败时保留未完成项对应元数据与父实勘，不能先级联删除导致失去重试路径。
已完成删除与未完成项明确区分；在线重试容忍文件已经不存在，不把部分失败称全成功。
对比仅选择本人活动记录 2–3 份，并列价格／现场平均／封面／水灾／持久化风险，不保存对比结果。

## 生命周期与验收责任

页面只在登录后的业务树内建立；退出成功或换账号后结束旧业务页面，新页面按当前 SDK 用户读取记录。
Widget／ViewModel 在 dispose 后忽略晚到结果。账号记录只在线保存，网络失败显示未保存并允许用户重试；
不建立自动同步、清理屏障或离线队列。公共分析保留真实来源、日期、缓存／部分／不可用状态，不以零替代缺失。

主要验收 seam 为应用页面入口；使用可见内容、动作、导航与保存／读取结果断言。
复用仍有效的公式、地理、Adapter 与存储测试，完成格式、分析、测试、debug APK 构建。
本次重构的统一证据见 [Issue #31 执行检查](../system/issue-31-validation.md)；
设备、真实外部服务证据缺失时不得宣称新版本 `Implemented` 或 `Integrated`。
