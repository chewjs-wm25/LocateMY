# 关键用户流程（Issue #31）

1. 启动读取 SDK 当前用户：有用户创建业务页，无用户显示登录；SDK 负责重启保持登录。
2. 注册／登录：字段校验、加载、普通失败；成功进首页，不进入待验证或资料恢复分支。
3. 首页探索地图、返回首页；选合法单点看六类分析，两个不同点看中性 A/B。未实现项明确展示开发状态。
4. 收藏在线写入、读取、选择、删除；失败明确未保存／不可读取，用户重试，不排队。
5. 退出先确认，取消无副作用；SDK 当前设备退出成功结束业务路由回登录，失败普通反馈。
6. 换号重新创建页面、按新 SDK id 在线读本人数据；公共缓存、语言和导出副本保留。
7. 预算成功保存／选择 current 后预算压力和 Socio 收入位置更新。
8. 已保存预案导出 v1 JSON，重启／退出后仍可打开展示；坏文件／不支持版本失败且云端不变。
9. 隐患地图选点／长按 → 表单 → 发布 → 本人列表／详情；状态／删除／本人票在线保存，定位回地图。
10. 房产新增／编辑 → 返回式地图选点 → 在线保存；只新增／实际坐标变化查询风险，失败仍保存 unavailable。
11. 相机／相册在线照片；软删进回收站保留照片，恢复，确认永久清空依次删除文件／元数据／实勘；部分失败保留重试路径。

后续预算／房产流程是设计目标，不能以本流程文档声称当前应用已经实现。
不包含适配度总分、五偏好、私有数据清理证明、自建会话恢复或自动同步。
