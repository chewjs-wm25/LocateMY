# 系统关键流程

> 状态：`Draft — Issue #2 tracer scope`
> 最后更新：2026-09-13

当前文件只完成一个端到端 tracer。它证明启动/会话、应用导航、选址、一个公共地点分析、缓存、
权限和退出清理可以通过已登记系统 Interface 连成一条可验收链；其他必需关键流程仍待步骤 7。

## TRACER-01：启动、登录、选址、查看周边设施并退出

### 主成功路径

| 步骤 | 用户可观察行为 | Owner 与 Interface | 系统结果 | 步骤完成条件 |
| --- | --- | --- | --- | --- |
| 1. 启动 | 看到启动门控，而不是旧账户页面 | Application Shell → Authentication & Session `AUTH-001`；有会话时 → Account Privacy `PRIVACY-001` | 恢复当前设备会话；若无会话进入登录；有会话则打开同一账户范围 | 已得到分类会话结果；`authenticated` 时账户引用与 `opened` 范围一致；期间没有渲染私有路由 |
| 2. 登录 | 输入邮箱密码并提交；提交中禁用重复操作 | Authentication & Session `AUTH-001`；Application Shell → Account Privacy `PRIVACY-001` | 建立当前设备会话并打开相同账户的 `STATE-ACCOUNT-SCOPE` | `authenticated` 与同账户 `opened` 均成立后显示主应用 |
| 3. 进入地图 | 从首页切换到地图 Tab | Application Shell `SHELL-001` 内部导航规则；Map / Location 拥有页面状态 | 地图 Tab 打开且无旧账户地点 | 当前单点为空、地图可操作，或明确显示网络不可用 |
| 4. 点选地点 | 在地图点选马来西亚境内坐标，看到主色 Marker 与地点卡 | Map / Location `LOCATION-001` | 范围校验后替换 `STATE-LOCATION.single`，生成不可变地点引用 | Marker、卡片和引用指向同一坐标；A/B 未被改写 |
| 5. 打开分析 | 选择“周边设施” | Map / Location → Application Shell `SHELL-001`；输入来自 `LOCATION-001` | 以该不可变地点引用进入 Nearby Facilities | 路由被接受且页面不再读取可变全局选点 |
| 6. 查看结果 | 看到 2 公里五类覆盖、数量、每类最近三项、来源和时间 | Application Shell → Nearby Facilities `FACILITY-001`；Feature → OSM `FACILITY-002` | 完整查询经归类、去重、Haversine 圆形过滤后写 `CACHE-FACILITY` 并返回 `available fresh` | 数量、完整性、范围、来源、查询时间与 OSM 归因均可见 |
| 7. 退出 | 在账户页确认退出，随后回到登录页 | Authentication & Session `AUTH-001`；Application Shell → Account Privacy `PRIVACY-001` | 立即隐藏私有路由；结束本机会话；清除旧账户状态、私有缓存、队列和待传文件；重置导航/地点 | `STATE-SESSION` 已结束且 privacy barrier 为 `closed`；公共缓存与语言偏好仍在 |

### 启动与登录分支

| 情况 | 结果与恢复 |
| --- | --- |
| 启动有可接受的本机会话 | 打开对应账户范围后进入主应用；不得短暂显示其他账户内容 |
| 启动无会话或会话被远端拒绝 | 显示登录；拒绝不是可重试数据错误，也不恢复旧私有路由 |
| 会话需要远端刷新且设备离线 | 保持认证门控并显示可重试离线状态；未过期且 SDK 判定可接受的本机会话才可离线进入。最终有效性规则在 `AUTH-001` owning design 固定 |
| 已认证账户与待打开本机分区不匹配 | 视为不可重试的隔离失败：不开放主应用，结束本机会话并进入安全清理；不得尝试读取不匹配分区 |
| 匹配账户的本机分区暂时无法打开 | 保持认证门控并显示可重试本机错误；恢复后以同一账户引用重试，不回退到无分区主应用 |
| 登录凭据错误/邮箱格式无效 | 不可通过原提交直接重试的输入/凭据失败；保留邮箱，聚焦对应错误，密码只保留于当前页面内存 |
| 登录网络、超时或限流 | 可重试失败；保留安全输入状态并提供重试，不进入主应用 |
| 认证配置或客户端版本不受支持 | 不可重试失败；显示服务不可用与升级/联系维护者路径，不循环重试 |

### 选址与分析分支

| 情况 | 结果与恢复 |
| --- | --- |
| 未选择地点就打开分析 | `SHELL-001` 拒绝导航并提示先选择地点；不使用固定城市 |
| 坐标在马来西亚范围外或无效 | Map / Location 保留原合法状态或空状态，显示不可重试输入错误；用户重新点选 |
| 地图所需网络不可用 | 本项目不提供离线地图；没有已建立合法单点时无法完成新选址。恢复网络后重试；已有当前会话单点可继续作为显式分析输入 |
| 认证范围在操作期间关闭 | 所有主应用意图返回 `authentication required`；私有路由立即隐藏 |
| OSM 完整返回且有记录 | `available fresh`；展示每类数量、最近三项和覆盖摘要 |
| OSM 完整返回且五类均为零 | `complete empty`；显示“2 公里内暂无已收录周边设施”和“未收录不代表现实中不存在”，不是失败 |
| OSM 返回部分资料或完整性无法确认 | 对未知类别不显示零或未覆盖；若整体不能证明完整，返回不可用而非空结果 |
| 网络/超时/限流且有 24 小时内缓存 | `available cached`；显示上次成功时间和缓存标记，可在联网后重试 |
| 网络/超时/限流且无有效缓存 | `retryable unavailable`；显示“资料暂不可用”和重试操作 |
| 地点引用或分类映射版本不受支持 | `non-retryable unavailable`；要求返回重选地点或更新应用，不自动连续重试 |
| 用户主动刷新 | `FACILITY-001` 使用 `refresh` 绕过缓存；失败时仍可回落到未过期缓存并明确标注 |

### 退出与账户切换分支

| 情况 | 结果与恢复 |
| --- | --- |
| 在线退出 | 仅结束当前设备会话；其他设备保持登录。清理完成后显示登录页 |
| 离线退出 | 仍执行本机会话结束与本机 privacy barrier；不以网络失败阻止本地退出，也不删除远端业务记录 |
| 认证 SDK 的本机会话清除失败 | 私有 UI 立即关闭并继续执行 privacy barrier；登录入口保持关闭，显示可重试本机错误。确认属于不受支持的本机状态时显示不可重试恢复指引 |
| 某私有 Owner 清理失败 | 旧账户范围保持关闭，登录表单之外的主应用不渲染；显示本机清理失败与重试。失败 Owner 可定位，已清理 Owner 的重复调用保持幂等 |
| 在清理完成前尝试登录另一账户 | 登录入口保持关闭；`PRIVACY-001` 返回 `closed` 后才允许建立新账户范围 |
| 新账户登录 | 创建全新账户范围；不得读取或重放旧账户私有缓存、队列、草稿、待传照片或地点上下文 |
| 公共缓存与语言偏好 | 退出后保留；新会话可读取无账户标识的公共缓存，语言保持设备选择 |

## Tracer 验收场景

| ID | 前置条件与操作 | 预期证据 |
| --- | --- | --- |
| `AT-START-01` | 冷启动，无本机会话 | 只显示登录；主应用和旧私有内容从未出现 |
| `AT-START-02` | 冷启动，有可接受会话 | 对应账户范围打开后进入主应用；不会短暂显示错误账户 |
| `AT-START-03` | 注入账户引用不匹配与本机分区暂时不可读 | 前者结束会话并安全清理，后者保持门控并可重试；两者都不显示私有内容 |
| `AT-AUTH-01` | 用有效邮箱密码登录 | 建立真实会话并进入主应用；页面跳转前后账户引用一致 |
| `AT-AUTH-02` | 分别触发凭据错误、离线/超时和配置错误 | 三者分别呈现输入/权限、可重试、不可重试语义，均不进入主应用 |
| `AT-LOC-01` | 地图点选合法坐标后打开周边设施 | Marker、地点卡、路由输入和结果地点一致；范围明确为 2 公里 |
| `AT-LOC-02` | 无地点、范围外地点、离线且无既有地点分别尝试分析 | 不使用默认城市；分别显示缺失、非法和离线恢复路径 |
| `AT-FAC-01` | OSM 完整返回有记录 | 五类归类、总数、每类最近三项、来源、时间、范围和归因完整 |
| `AT-FAC-02` | OSM 完整返回零项 | 显示完整空结果和 OSM 覆盖限制，不显示失败或未知为零 |
| `AT-FAC-03` | 远端失败，分别准备有效缓存与无缓存 | 前者显示带时间的缓存结果，后者显示可重试不可用；主动刷新绕过缓存 |
| `AT-FAC-04` | 返回部分响应或不支持的地点/映射版本 | 部分响应不伪装完整空结果；不支持输入呈现不可重试恢复路径 |
| `AT-OUT-01` | 旧账户具备地点、私有缓存、收藏创建队列、房产草稿及待传照片后离线退出 | 本机会话和全部旧账户本机私有状态被清除，地点/导航重置；远端记录、公共设施缓存、语言和其他设备会话保留 |
| `AT-SWITCH-01` | 清理成功后登录另一账户 | 新账户看不到或同步不到旧账户任何本机私有状态；可复用无账户标识的公共缓存 |
| `AT-OUT-02` | 分别注入认证 SDK 本地清除失败和一个 Owner 的本机清理失败 | 私有 UI 保持关闭且新登录受阻；显示分类错误并指出失败环节，可重试错误恢复后能完成 |
