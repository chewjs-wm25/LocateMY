# 系统关键流程

> 状态：`Draft — Issue #4 complete cross-Feature flows`
> 最后更新：2026-09-13

本文件是跨 Feature 工作流顺序、失败/降级与恢复语义的唯一真相。步骤只引用
[Interface 注册表](interfaces.md)和[数据所有权](data-ownership.md)，不复制字段或 Feature 内部算法。
每个流程均覆盖成功、失败、不可用、权限和适用恢复；不适用的分支明确说明。

## FLOW-01：启动、注册/登录、退出与账户切换

### 成功顺序

1. Application Shell 显示认证门控，通过 `AUTH-001` 恢复当前设备会话；私有路由尚未建立。
2. 无会话时保持登录/注册入口；注册返回 `verification required` 时显示查收邮件状态，不伪装已登录。
3. `authenticated` 后以同一账户调用 `PRIVACY-001.open`；只有 `opened` 才创建该账户私有 ViewModel 并进入主应用。
4. 退出/换号先隐藏私有 UI、拒绝新业务意图并取消/忽略旧请求；`AUTH-001` 结束当前设备会话，`PRIVACY-001.close` 汇总全部 Owner 清理。
5. 两者完成后显示普通登录入口；换号再为新账户重复 1–3。公共缓存与语言保留，远端业务记录和其他设备会话不变。

| 分支 | 系统结果 | 用户恢复 |
| --- | --- | --- |
| 恢复无会话或远端拒绝 | `unauthenticated`，只显示登录；旧 scope 不打开 | 正常登录 |
| 离线且 SDK 无可接受会话 | retryable unavailable，停在门控 | 恢复网络后重试；不进入无 scope 主应用 |
| 登录凭据/表单错误 | validation/permission failure，保留邮箱、聚焦错误；密码仅页面内存 | 修正后重提 |
| 网络、超时、限流 | retryable failure，不创建 scope | 用户重试 |
| 配置/客户端不支持 | non-retryable failure | 升级/联系维护者；不循环重试 |
| Auth 账户与 scope 不同 | identity mismatch；结束会话并安全关闭 | 清理完成后重新登录 |
| 任一私有 Owner 清理失败 | 私有 UI 保持关闭，新登录受阻；结果列出 Owner | 幂等重试失败 Owner；进程重启仍先完成 barrier |
| 未认证访问主应用 | `authentication required` | 返回登录 |

验收：`AT-AUTH-01` 冷启动无/有会话；`AT-AUTH-02` 注册两种结果与真实确认状态；`AT-SWITCH-01` 两账户全 Owner 隔离；`AT-OUT-01` 在线/离线退出；`AT-OUT-02` Auth/清理故障注入。

## FLOW-02：单点选址、地点摘要与六类分析

### 成功顺序

1. 用户在 OSM 地图点选，或选择 `LOCATION-003` 候选；`LOCATION-001` 完成马来西亚范围校验并产生不可变 single 引用。
2. Map 更新 single Marker/详情卡；Shell 以同一引用并行请求 Safety、Cost、Facilities、Transit、Infrastructure 与 Suitability 摘要。社会经济只在完整分析中请求。
3. 每个提供方返回自身带日期、来源、口径与可用性的结果；Shell 渐进组合，不把较慢结果阻塞成整页失败。
4. 用户进入六类任一分析时，`SHELL-001` 把当前不可变引用传给目标 Feature；页面不回读之后变化的全局选点。

| 分支 | 系统结果 | 用户恢复 |
| --- | --- | --- |
| 无地点/非法坐标/范围外 | Shell 拒绝分析；原合法点或空状态保留；无默认城市 | 重新点选或搜索 |
| 地图/Geoapify 离线 | 无既有合法引用时不能新选址；已有引用仍可用于允许缓存的分析 | 恢复网络；或继续查看明确缓存结果 |
| 一个分析失败 | 该卡显示 retryable/non-retryable unavailable，其他卡保留 | 卡内重试或返回重选；刷新不改地点 |
| complete empty / zero | Facilities 完整零项、Transit no stops 等按各自语义展示，不写成失败或未知 | 无需恢复；可主动刷新 |
| 部分/未知 | 不生成依赖该完整性的指标；保留成功分项和原因 | 数据恢复后重试 |
| scope 在请求中关闭 | 旧结果丢弃，返回 `authentication required` | 完成 FLOW-01 后重新开始 |
| 晚到旧地点结果 | 由请求地点/版本拒绝，不覆盖新地点卡 | 无用户动作 |

验收：`AT-LOC-01` 点选/候选/六类路由同点；`AT-LOC-02` 缺失、范围外与离线；`AT-ANALYSIS-01` 六类 fresh/cached/empty/partial/unavailable；`AT-RACE-01` 快速换点与换号。

## FLOW-03：地点 A/B 比较

### 成功顺序

1. 用户显式把地点设为 A 或 B；`LOCATION-001` 保持 single 与 A/B 状态分离，阻止同一点。
2. 两端有效后 Shell 建立一次比较请求，对六类分析分别传入 A/B 不可变引用；每个 Feature 复用自己的单点 Interface 语义并判断本域可比性。
3. 总览并列两端原生主读数；详情保留来源、日期、地理/半径口径、缓存/估算与不可比原因。交换只交换呈现顺序。
4. `SUITABILITY-001` 仅在两端均可计算时作为独立摘要并列，不进入六类总分且不标赢家。

| 分支 | 系统结果 | 用户恢复 |
| --- | --- | --- |
| 缺 A/B 或同点 | 停留补全状态；字段级原因 | 补选不同地点 |
| 单域一侧失败/不可用 | 保留另一侧；该域不计算差异 | 重试失败侧或接受不可比 |
| 两侧层级/年份/单位不可比 | 并列原值与原因，不生成差异 | 选择资料口径可比地点或等待资料 |
| 网络失败有缓存 | 各侧独立标记 cached/stale；只有契约允许时比较 | 联网刷新 |
| 权限/scope 关闭 | 整个比较退出私有路由 | 登录后重新选择；不恢复旧账户 A/B |
| 交换时请求未完成 | 请求结果仍绑定地点 id，交换只改变显示槽位 | 无需重查；过期请求不入槽 |

验收：`AT-COMPARE-01` 六域真实 A/B 与交换；`AT-COMPARE-02` 缺端/同点；`AT-COMPARE-03` 单侧缺失、口径不可比和缓存混合；`AT-COMPARE-04` 无自动推荐。

## FLOW-04：收藏地点离线创建与前台同步

### 成功顺序

1. authenticated 用户命名合法地点。在线时 `LOCATION-001` Owner 写 `user_saved_locations`；离线时写同账户 `saved_location_create_queue`，UI 显示“已排队”。
2. 冷启动已打开 scope、登录后、回到前台或用户手动重试时，Map 读取自己的队列，按 client id/idempotency key 依序创建远端记录。
3. 成功项转为 `saved_location_cache` 的远端记录并移出队列；随后按远端版本拉取本账户变更，合并记录与删除墓碑，实现换设备恢复和删除传播。
4. 删除只在线；远端成功后写入可同步墓碑并更新本机缓存。另设备下一次前台同步移除用户可见项；旧缓存或晚到 create 不得复活该项。

| 分支 | 系统结果 | 用户恢复 |
| --- | --- | --- |
| 离线创建 | queued，不显示 created/synced | 自动前台重试或手动重试 |
| 重复提交/重放 | 同一 idempotency key 至多一个远端收藏 | 同步继续，不生成重复项 |
| 名称/地点非法 | validation failure，不入队 | 修正后重提 |
| 网络/超时 | 保留队列、attempt 和 retryable error | 下次前台或手动重试 |
| 权限/账户不匹配 | non-retryable isolation failure；不改写 owner | 关闭 scope并走 FLOW-01 清理 |
| 远端与本机冲突 | Supabase 权威；保留可说明的失败，不以旧缓存覆盖远端 | 刷新后让用户重做在线动作 |
| 离线编辑/删除 | 明确不支持，不排队 | 联网后完成 |
| 换号 | 旧缓存/队列在 barrier 中删除，绝不以新账户重放 | 新账户从自己的远端恢复 |

验收：`AT-SAVED-01` 在线 CRUD/换设备恢复；`AT-SAVED-02` 离线创建、重启、幂等同步；`AT-SAVED-03` 删除传播；`AT-SAVED-04` 换号与权限失败。

## FLOW-05：公共隐患、投票与本人管理

### 成功顺序

1. 用户从入口或地图长按取得合法坐标，经 `SHELL-001` 打开表单；类型不预选，trim 后标题与类型必填。
2. `HAZARD-001` 在线创建远端报告；成功后发布 created 结果，地图通过 `LOCATION-002` 刷新公开图层并可打开详情。
3. authenticated 用户可分页/viewport 读取公开报告；本人可改自己的 `pending/resolved` 状态或删除自己的报告。创建提交前可修正表单输入；成功发布后内容、位置和上报时间不可编辑。
4. 赞成/反对写本人唯一投票，撤回删除该行；显示计数只来自 authenticated 的受控
   `hazard_vote_counts` RPC，且不返回投票者身份。

| 分支 | 系统结果 | 用户恢复 |
| --- | --- | --- |
| 表单非法/范围外 | validation failure，不写远端 | 修正字段/位置 |
| 写入网络失败 | retryable failure；首版不排队且不显示成功 | 保留安全表单状态并在线重试 |
| 未认证 | `authentication required`；公共隐患在本产品仍限 authenticated | 登录后重试 |
| 非作者更新状态/删除，或作者修改已发布内容 | permission/contract failure，记录不改变 | 返回详情；不展示不允许的操作 |
| 修改他人投票/直接计数 | permission/contract failure | 只允许本人投票动作 |
| 图层分页失败 | 保留已成功页并标记不完整，不把缺页当无隐患 | 重试当前 viewport |
| 报告被并发删除/改变 | conflict/not found，刷新详情和计数 | 返回图层或重新操作 |
| 治安分析 | 隐患不进入 `SAFETY-001` 分数或州级犯罪统计 | 不适用 |

验收：`AT-HAZARD-01` 五类创建/详情/本人列表；`AT-HAZARD-02` viewport 分页与失败；`AT-HAZARD-03` 两账户作者权限；`AT-HAZARD-04` 投票切换/撤回/计数；`AT-HAZARD-05` 离线写不伪装排队。

## FLOW-06：房产实勘、照片、风险快照与回收站

### 成功顺序

1. 新增/编辑使用 `LOCATION-001` 返回式地图选点；表单写同账户 `property_drafts`，离开/重启可续填。
2. 新建或坐标改变时，Shell 并行请求 `SAFETY-001` 与 `HAZARD-002`。两项及采集时间齐全后，Property 把风险上下文随实勘写入远端；任一失败则保存业务表单为草稿或报告风险失败，不制造部分新快照。
3. 相机/相册文件复制并压缩到应用目录，写 `property_photo_upload_queue`。联网后先验证父实勘 owner，再上传私有 Storage 文件并写照片元数据；成功后删除本机待传副本。
4. 详情显示保存时快照和时间。用户显式刷新时再次并行取得两项；全部成功才原子替换快照，失败保留旧快照并说明。
5. 删除写 `deleted_at` 进入可见回收站；恢复清除软删除。确认清空只处理当前账户回收站项，并永久删除照片文件、元数据与实勘记录。对比只读取 2–3 个当前账户活动记录。

| 分支 | 系统结果 | 用户恢复 |
| --- | --- | --- |
| 地点/表单非法 | validation failure；草稿保留 | 修正后重提 |
| 风险来源 unavailable | 新/变更坐标不产生不完整快照；旧快照不覆盖 | 重试风险采集；可继续编辑草稿 |
| 非当前账户记录/文件 | permission failure，无内容泄露 | 返回档案并执行隔离检查 |
| 离线添加照片 | 本机可见 `pending upload`；不称远端已保存 | 前台自动同步/手动重试 |
| 上传成功、元数据失败或反向 | 显示可重试不一致状态；队列保留补偿目标 | 重试到两者一致；只清理可证明孤儿 |
| 超过 20 张/不支持格式/压缩失败/设备权限拒绝 | 分类失败，不破坏已有照片 | 删除照片、换格式或授予权限后重试 |
| 单张照片离线删除 | 首版不支持且不隐藏原照片、不建立删除队列 | 联网后重试；在线失败时保留原照片并显示错误 |
| 清空部分失败 | 未完成项留在回收站并列明；不报告全部成功 | 重试失败项；已删项幂等 |
| 换号有待传文件 | barrier 删除旧账户草稿、queue 和本机文件；远端已上传对象保留 | 旧账户重新登录后从远端恢复已成功项 |

`HAZARD-002` 固定按房产坐标 2,000m Haversine 圆形（`d <= 2,000m` 含边界）只计公开
`pending` 报告；结果携带半径、统计时间和可用性，`resolved`、失败或 partial 不当 0。Property
在两项风险输入完整时才随快照保存，具体运行时证据仍由 `RISK-PROP-01` 追踪。

验收：`AT-PROP-01` 草稿/新增/编辑/重启；`AT-PROP-02` 20 张、封面、说明和离线上传；`AT-PROP-03` 风险创建/坐标变化/显式刷新/失败保留；`AT-PROP-04` 两账户隔离；`AT-PROP-05` 2–3 对比；`AT-PROP-06` 回收站恢复与部分失败清空。

## FLOW-07：偏好、当前评估预案与个人化地点适配度

### 成功顺序

1. Account Center 通过 `ACCOUNT-001` 保存五项 `1–10` 评估偏好；Cost 通过 `COST-002` 保存预算预案并发布 current 或无 current 的事实（完整预案语义见其 owning design）。
2. 成功写入后发布带版本的变化事实；Shell 使当前账户相关地点摘要/A-B 适配度请求失效并重新组合。
3. `SUITABILITY-001` 读取同一账户偏好、current 预案语境，以及同一地点的 Safety、个人预算压力、Facilities、Transit 和中性 ICI。
4. 全部中/高优先级维度可用时计算；低优先级缺失可排除并说明；A/B 只有两端均可算时并列。

| 分支 | 系统结果 | 用户恢复 |
| --- | --- | --- |
| 偏好或 current 预案缺失 | prerequisite missing，不用默认值生成适配度 | 打开对应设置入口 |
| 预案字段/成本质量不足 | 成本维度 unavailable；中/高优先级则总分不可用 | 补齐预案或等待完整资料 |
| 分析维度未知/无路线/incomplete | 保留提供方原因；明确零仍为 0 | 重试提供方或调整已确认偏好 |
| 所有维度不可用 | 固定不可用文案，不显示 0/部分分 | 恢复输入资料 |
| 保存网络/权限失败 | 不发布变化，不使用未保存值冒充账户状态 | 在线重试；换号时清理 |
| 旧版本结果晚到 | 版本不匹配即丢弃 | 无用户动作 |

验收：`AT-SUIT-01` 五维正常与公式输入同源；`AT-SUIT-02` prerequisites；`AT-SUIT-03` 低/中/高缺失；`AT-SUIT-04` 预案切换即时重算；`AT-SUIT-05` A/B 无赢家；`AT-SUIT-06` 换号隔离。

## FLOW-08：首页刷新与探索地图

### 成功顺序

1. opened 主应用通过 `HOME-001 cache-allowed` 读取全国指标；每项保留自己的观测日期，Shell 渐进呈现。
2. 按钮或下拉调用同一 `refresh`；成功后重算搬家时机并开始 60 秒内存冷却。
3. “探索地图”发 `SHELL-001` 导航意图切换地图 Tab；不自动选择地点。

| 分支 | 系统结果 | 用户恢复 |
| --- | --- | --- |
| 单数据集缺失 | 对应分项 unavailable；若必需分项缺失则总分 unavailable，其他卡保留 | 刷新或查看日期/原因 |
| 网络失败有缓存 | cached/stale，显示上次成功时间与观测日期 | 联网重试 |
| 网络失败无缓存 | retryable unavailable | 联网重试；仍可进入地图 |
| 冷却期重复刷新 | 拒绝重复请求并显示剩余秒数 | 冷却结束后重试 |
| 未认证/scope 关闭 | authentication required | 登录后进入 |
| 导航被门控拒绝 | 保持当前页，无隐式路由 | 完成认证/scope 恢复 |

验收：`AT-HOME-01` fresh/partial/cache/no cache；`AT-HOME-02` 按钮/下拉同语义与冷却；`AT-HOME-03` 探索地图不制造默认地点。

## 原型冲突处置

| 原型/旧 schema 表现 | 权威处置；实现者无需选择 |
| --- | --- |
| 启动直进首页、固定 verified、退出只跳页 | FLOW-01 的真实 Auth + privacy barrier |
| 静态地图、预设地点、固定默认城市 | OSM + Geoapify 候选 + 最终马来西亚范围校验；无地点即拒绝分析 |
| 收藏布尔值/固定列表/旧 `user_saved_regions` | `user_saved_locations` + 账户 SQLite 缓存/离线创建队列 + 前台双向同步 |
| A/B 五域硬编码 fixture | FLOW-03 逐端调用真实单点结果，缺失/不可比明确显示 |
| 社会经济页“不插值”旧文案 | 用户收入位置按 canonical 相邻百分位线性插值 |
| ICI 原型权重 7/4/8 或旧五权重表 | 医疗/教育/交通默认 5；只影响单点账户 ICI；中性 ICI 固定 5 |
| 隐患固定列表、内存投票、verified/rejected | 真实公共远端报告；作者权限；持久化每账户投票；状态仅 pending/resolved |
| 临时月支出被当预案 | 只做页面内存 CPI 等效换算；预算压力/适配度只读 current 预案 |
