# 视图层：社会经济组件

## 描述
用于评估家庭收入分布和经济平等状况的仪表盘。

## 关键 UI 元素
- **收入阶层标签**：所选地区的 B40 / M40 / T20 门槛。
- **地区排名**：与同州内其他地区的对比。

## 数据可视化
- **收入分布图（正态分布曲线/直方图）**：
    - **用途**：展示所选地区的中位数收入在全国平均水平中的位置。
    - **数据源**：`hh_income_district`。
- **基尼系数仪表盘**：
    - **用途**：可视化地区内的收入不平等程度。
    - **数据源**：来自 OpenDOSM 的基尼系数。

## 交互
- 通过滑块“输入月收入”，查看在该地区的百分比排名。
