# 视图层：气候与水灾风险组件

## 描述
环境风险安全仪表盘，重点关注季节性水灾。

## 关键 UI 元素
- **风险等级卡片**：高/中/低水灾风险状态。
- **7 天天气预报卡片**：每日天气概况。

## 数据可视化
- **水灾风险地图图层叠加**：
    - **用途**：在地图上叠加历史水灾高发点和实时河流水位。
    - **数据源**：JPS InfoBanjir 和 MYSA 土地利用数据。
- **历史降雨量柱状图**：
    - **用途**：月度平均降雨量，用于识别季风高峰期。
    - **数据源**：MetMalaysia 气候数据。

## 交互
- 切换地图图层：“历史水灾点”、“实时警报”。
