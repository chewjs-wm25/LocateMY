# 视图层：基础设施组件

## 描述
公用设施和公共服务覆盖率（ICI 指数）的综合视图。

## 关键 UI 元素
- **ICI 计分板**：显著展示计算得出的综合基础设施普及率指数。
- **服务状态图标**：水、电、医疗、教育的状态切换。

## 数据可视化
- **ICI 雷达图（蛛网图）**：
    - **用途**：展示水、电、医疗和教育覆盖率之间的平衡状况。
    - **数据源**：来自 `hh_access_amenities`、`hospital_beds` 和 `school_enrolment` 的加权得分。

## 交互
- **权重调整滑块**：允许用户更改“医疗”与“教育”的重要性，从而实时更新 ICI 分数和雷达图。
