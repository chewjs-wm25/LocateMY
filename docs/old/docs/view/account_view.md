# 视图层：账户组件

## 描述
用户个人资料管理和身份验证 UI。

## 关键 UI 元素
- **登录界面**：
    - 邮箱文本框。
    - “发送魔术链接”按钮。
    - “以游客身份继续”链接。
- **个人资料界面**：
    - 用户头像和邮箱显示。
    - **偏好设置部分**：默认地点的切换开关。
    - **保存的对比**：此前查看过的地区列表。
- **互动部分**：
    - “我的评论”和“已点赞/点踩”的地区列表。

## 交互
- 邮箱格式验证。
- 魔术链接发送后的提示信息（Toast）。
- 确认“退出登录”或“注销账户”的模态弹窗。
