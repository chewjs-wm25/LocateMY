# 视图层：马来西亚宏观时机仪表盘 (Home View)

## 描述
这是应用程序的首页，旨在为用户提供马来西亚宏观环境的概览，帮助其判断当前是否是搬迁的理想时机。该页面采用 Bento Grid 设计风格，整合了经济、就业、物价及气候等核心指标。

## 关键 UI 元素 (Bento Grid 布局)
1. **宏观搬迁时机综述卡片 (Hero Card)**:
    - **显示内容**: 当前综合评分（例如：7.5/10）及一段简短的建议（如：“当前物价稳定且非雨季，是理想的搬迁窗口”）。
    - **组件**: `HeroBannerCard` + `StatusBadge`。
2. **通货膨胀与物价趋势卡片**:
    - **显示内容**: CPI (消费者物价指数) 增长率，细分为食品、住房和交通支出。
    - **组件**: `NationalInflationCard`。
3. **就业与收入指标卡片 (KPI Row)**:
    - **显示内容**: 当前全国失业率及家庭月收入中位数。
    - **组件**: `KPIMetricRow`。
4. **经济增长趋势图**:
    - **显示内容**: 近五年的 GDP 增长率走势。
    - **组件**: `LineChartCard` (基于 `fl_chart`)。
5. **季节性气候风险预警**:
    - **显示内容**: 当前是否处于季风季节 (Monsoon)，搬家过程中的降雨/水灾风险提示。
    - **组件**: `ClimateWarningCard`。

## 数据可视化
- **GDP 趋势折线图**:
    - **用途**: 展示经济活跃度，判断市场信心。
- **CPI 分布条形图/饼图**:
    - **用途**: 直观显示生活成本的变动分布。
- **搬迁综合指数计速器/环形进度条**:
    - **用途**: 位于 Hero 卡片中，直观表达“搬迁推荐指数”。

## 交互
- **点击“开始探索”**: 导航至空间选址比对页 (Spatial Selection Map)。
- **点击具体指标卡片**: 展开查看更详细的历史数据或跳转至对应的深度解析页面（如财务或气候页面）。
- **刷新功能**: 下拉刷新以获取最新的 Open Data API 数据。
