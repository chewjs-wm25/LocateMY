# 社会经济阶层与收入基准仪表盘

## 1. 模块简介与定位
- **模块名称**：社会经济阶层与收入基准仪表盘 (Socioeconomic Class & Income Benchmark Dashboard)
- **功能描述**：在 Flutter 移动端展示各州及各县的家庭中位数收入、Gini 不平等指数及 B40/M40/T20 门槛变化，帮助用户评估目标社区的社会经济阶层结构。同时集成宏观经济背景对照，帮助用户在宏观与微观两个维度审视搬家决策的时机与适应度。

## 2. 决策维度剖析与用户价值
- **人口结构与区域经济活力维度**：
  - 各县的劳动参与率、失业率及家庭中位数收入增长轨迹，反映了目标区域的就业市场吸纳能力与商业繁荣度。
  - 是用户评估未来职业发展机会、薪资水平匹配度与长期房产增值潜力的重要依据。

## 3. 核心数据源与 API 规范 (100% 免费公开数据)

### 3.1 家庭收入、贫困与阶层数据 (`hh_income_district`)
- **数据机构**：马来西亚统计局 (OpenDOSM)
- **数据内容**：提供行政县级的家庭平均月收入、中位数月收入、贫困率及 Gini 指数。
- **API 端点**：`GET https://api.data.gov.my/opendosm?id=hh_income_district`
- **关键提取字段**：`district`, `income_mean`, `income_median`, `poverty_rate`, `gini`
- **更新机制**：每 2-3 年（基于 HIES 家庭收入与支出调查周期）。
- **应用场景**：B40 / M40 / T20 收入阶层划分与县域家庭中位数收入横向对比。

### 3.2 宏观经济背景对照 (World Bank Open Data API)
- **数据机构**：世界银行 (World Bank)
- **数据内容**：国家层面的宏观经济汇总指标，如马来西亚整体 GDP 增长率、全国基尼系数、城镇化率等。
- **API 端点**：`GET https://api.worldbank.org/v2/country/mys/indicator/NY.GDP.MKTP.CD`
- **关键提取字段**：`indicator`, `date`, `value`
- **更新机制**：按年度更新。
- **费用与限制**：完全公开免费，无需鉴权。

## 4. Flutter 客户端展现与 Supabase 架构集成

### 4.1 技术选型与 0 成本保证
- **Flutter 前端**：
  - 使用 `fl_chart` 的 `BarChart` 与 `LineChart` 渲染县域家庭收入分位数分布与历史增长曲线。
  - 采用 Bento Grid 卡片布局展示 Gini 系数与贫困发生率。
- **Supabase Free Tier 后端**：
  - 用户可在个人配置中记录当前家庭月收入，由 Supabase Auth + Postgres 安全存储，与目标县的 B40/M40/T20 门槛进行实时定位比对。
  - **完全免费，无需绑定信用卡**。

### 4.2 数据库 Schema 与用户档案集成

```sql
CREATE TABLE user_income_benchmarks (
  benchmark_id UUID PRIMARY KEY DEFAULT uuid_generate_v4(),
  user_id UUID NOT NULL UNIQUE REFERENCES auth.users(id) ON DELETE CASCADE,
  monthly_household_income DECIMAL(10,2) NOT NULL,
  household_size INT NOT NULL DEFAULT 1,
  target_district VARCHAR(64),
  updated_at TIMESTAMPTZ NOT NULL DEFAULT NOW()
);

ALTER TABLE user_income_benchmarks ENABLE ROW LEVEL SECURITY;

CREATE POLICY "User Benchmark Access"
  ON user_income_benchmarks
  FOR ALL
  USING (auth.uid() = user_id)
  WITH CHECK (auth.uid() = user_id);
```

### 4.3 Flutter Dart 集成实现示例

```dart
import 'package:flutter/material.dart';
import 'package:supabase_flutter/supabase_flutter.dart';
import 'package:fl_chart/fl_chart.dart';

class SocioeconomicService {
  final _supabase = Supabase.instance.client;

  // 保存用户家庭基线收入并获取分位数阶层
  Future<void> saveUserIncome({
    required double monthlyIncome,
    required int householdSize,
    required String targetDistrict,
  }) async {
    final user = _supabase.auth.currentUser;
    if (user == null) return;

    await _supabase.from('user_income_benchmarks').upsert({
      'user_id': user.id,
      'monthly_household_income': monthlyIncome,
      'household_size': householdSize,
      'target_district': targetDistrict,
      'updated_at': DateTime.now().toIso8601String(),
    });
  }
}
```
