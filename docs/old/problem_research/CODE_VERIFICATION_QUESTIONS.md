# LocateMY 代码验证问题清单

## 使用说明

本文件只收录无法从截图可靠判断、需要结合当前项目代码确认的问题。请研究实际项目代码后逐题回答，不要依据旧文档推测。

回答要求：

- 说明当前实际行为，而不是理想行为或重构建议。
- 如果界面存在但按钮无操作，请明确写“仅有界面，当前无功能”。
- 如果数据是固定示例、只保存在内存、保存在本机或保存到远端，请明确说明。
- 如果问题描述与代码不一致，请以代码为准指出差异。
- 每题附上能够证明结论的主要代码文件和行号。

建议回答格式：

```text
Qxx：
结论：
实际行为：
数据是否持久保留：
证据文件与行号：
```
