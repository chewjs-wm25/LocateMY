# LocateMY 功能知识库

## 1. 文档用途

本文档整理 LocateMY 当前产品的功能范围，作为重新开发时的产品基线。

整理原则：

- 以当前应用截图所呈现的功能和界面语义为主。
- 其他文档只用于补充截图未完整展示、但与截图中入口或业务对象直接相关的功能。
- 不记录算法、评分公式、系统架构、代码分层、数据库表、RPC 或第三方服务的实现方式。
- 不把旧设计中的规划功能自动视为重开发范围。
- 无法从现有资料确定的行为统一收录在
  [CODE_VERIFICATION_QUESTIONS.md](./CODE_VERIFICATION_QUESTIONS.md)，待代码研究后回填。

## 2. 产品定位

LocateMY 是一款面向马来西亚搬迁与居住选址的移动应用。用户可以选择一个地点，或对比原居住地与目标地点，从宏观经济、生活成本、治安、社会经济、基础设施、周边设施和公共交通等角度了解地区，并保存地点、预算预案、房产实勘与隐患报告等个人资料。

## 3. 功能范围总览

| 功能域 | 主要能力 |

| 基础设施 | 综合覆盖指数、供水供电、医疗教育、个性化需求权重 |
| 周边设施 | 设施分类、数量、最近设施、距离和覆盖情况 |

## 4. 全局功能

### 4.1 身份访问

- 未登录用户使用登录和注册界面。
- 登录成功后进入应用主体。
- 已登录用户可以从账户中心退出登录。
- 用户身份区域显示邮箱和已验证标识。

### 4.2 语言

- 支持 English 与中文两种界面语言。
- 登录页提供中英文切换按钮。
- 应用首页顶部提供语言菜单，并显示当前选中语言。

### 4.3 主界面

- 主导航包含“首页”和“地图”两个一级页面。
- 首页顶部提供数据刷新、语言和账户中心入口。
- 各分析页和资料页提供返回上一级页面的能力。

## 5. 登录与注册

### 5.1 登录

- 使用邮箱和密码登录。
- 密码输入支持显示或隐藏。
- 提供进入注册页的入口。
- 登录页可直接选择中文或 English。

### 5.2 注册

- 填写用户名、邮箱、密码和确认密码。
- 密码与确认密码均支持显示或隐藏。
- 提交后创建新账户。
- 提供返回登录页的入口。

## 6. 首页

首页用于快速展示整体搬迁环境，并引导用户进入地点探索。

### 6.1 搬迁时机

- 展示当前是否处于适宜搬迁的时期。
- 展示搬迁指数。
- 展示简短的搬迁建议和原因说明。

### 6.2 宏观指标

- 失业率及其变化。
- 收入中位数及其变化。
- CPI 通胀率。
- OPR 利率。
- 历年经济增长（GDP）趋势图。

### 6.3 首页操作

- 手动刷新首页数据。
- 点击“开始探索地点”进入地图。
- 切换界面语言。
- 进入账户中心。

## 7. 地图与选址

地图是地点选择、地点对比、收藏、隐患和地区分析的中心工作区。

### 7.1 地图浏览与搜索

- 浏览、移动和缩放马来西亚地图。
- 通过搜索框查找地点。
- 在地图上选择地点并显示位置标记。
- 刷新地图相关内容。

### 7.2 显示模式

- 对一个选中地点进行查看和分析。
- 当前地点作为各类地区分析的目标地点。

### 7.3 对比模式

- 分别选择“原地址”和“新地址”。
- 两个地点共同供生活成本、治安、社会经济和基础设施等对比页面使用。
- 地图清楚标示当前正在选择原地址还是新地址。

### 7.4 收藏地点

- 打开已收藏地点列表。
- 从收藏列表选择地点。
- 保存常用地点。
- 删除不再需要的收藏地点。
- 收藏为空时显示空列表提示。

### 7.5 地图图层与快捷入口

- 显示或隐藏众包隐患标记。
- 查看地图上的隐患信息。
- 打开地区分析功能集合。
- 从地图发起新的隐患报告。

### 7.6 地区分析集合

选中地点后，用户可以查看以下分析：

- 生活成本分析。
- 治安与犯罪风险。
- 社会经济分析。
- 基础设施评估。
- 周边设施评估。
- 公共交通与通勤。

## 8. 生活成本分析

生活成本功能用于比较原地址与新地址的购买力和日常开销。

### 8.1 地点与预案

- 显示原地址和新地址。
- 选择已有预算预案。
- 新建预算预案并命名。
- 重命名预算预案。
- 删除预算预案。

### 8.2 购买力与预算

- 输入当前月支出预算。
- 根据两地生活成本展示目标地点所需的等效预算。
- 用文字说明维持当前生活方式所需预算的增减幅度。
- 对照展示原地区和目标地区的 CPI。

### 8.3 商品与支出

- 展示目标地点常见生活必需品的平均价格。
- 每个商品展示名称与马币价格。
- 提供查看相关商家的入口。
- 展示两地可比较项目的支出对比。
- 当不存在相同可比商品时显示无可比内容。

## 9. 治安与犯罪风险

该功能用于了解选中地区的整体治安水平，并与房产实勘结合。

### 9.1 房产实勘概览

- 展示已保存的房产实勘档案。
- 每项显示房产名称和评分。
- 提供房产档案入口。
- 提供新增房产入口。

### 9.2 地点对比

- 显示原地址和新地址。
- 以当前选中地区作为安全分析对象。

### 9.3 安全地图

- 展示当前地区的安全地图图层。
- 展示地区边界。
- 展示选中位置标记。
- 切换边界或隐患相关图层。
- 提供返回主地图查看的入口。
- 展示区域安全等级标签。

### 9.4 治安指标

- 展示整体安全指数。
- 展示地区名称和最近一年案件数量。
- 展示犯罪类别，包括全部、暴力犯罪和财产犯罪。
- 展示按年份变化的犯罪率趋势图。

## 10. 社会经济分析

该功能用于了解选中地区的家庭收入结构和不平等情况。

### 10.1 地点对比

- 显示原地址和新地址。
- 以当前选中地区作为社会经济分析对象。

### 10.2 收入阶层

- 展示 B40、M40、T20 三类收入阶层的占比。
- 展示地区家庭收入中位数。
- 展示 B40 与 T20 的收入门槛。
- 标示数据年份和统计口径说明。

### 10.3 地区指标

- 展示地区发展排名及参与排名的地区总数。
- 展示基尼系数。
- 用文字标签说明不平等程度。
- 展示与上一统计期相比的变化。

### 10.4 收入分布与个人位置

- 展示家庭月收入分布曲线。
- 在图表中标示收入中位数。
- 允许用户输入家庭月收入。
- 展示用户收入在地区收入分布中的相对位置。

## 11. 基础设施评估

该功能用于查看地区公共服务覆盖，并允许用户按个人需求调整关注重点。

### 11.1 地点对比

- 显示原地址和新地址。
- 以当前选中地区作为基础设施分析对象。

### 11.2 综合与分项指标

- 展示基础设施综合覆盖指数（ICI）。
- 数据不完整时显示明确提示。
- 展示供水覆盖。
- 展示供电覆盖。
- 展示医疗资源或医疗密度。
- 展示教育资源。
- 缺少某项数据时用缺省符号表示。

### 11.3 个性化需求

- 调整医疗服务重要性。
- 调整教育资源优先级。
- 调整商业便利性。
- 展示调整后的综合结果。

## 12. 周边设施评估

该功能用于查看选中地点一定范围内的生活设施。

### 12.1 地点选择与概览

- 选择一个地点进行评估。
- 展示已获取的设施总数。
- 展示设施覆盖的类别数量。

### 12.2 设施分类

- 医疗健康（Healthcare）。
- 教育资源（Education）。
- 日常生活（Living & Amenities）。
- 交通出行（Transport）。
- 安全与服务（Safety & Services）。
- 休闲与绿地（Leisure & Parks）。
- 灾害与环境风险（Risk）。

### 12.3 分类内容

- 展示每一类别的设施数量。
- 展示距离最近的设施名称和距离。
- 展示该类别覆盖的设施类型数量。
- 列出附近设施的名称、类型和距离。
- 类别无结果时显示范围内暂无已收录设施。

## 13. 公共交通与通勤

该功能用于了解选中地点周边公共交通站点和连接便利度。

### 13.1 地点与评分

- 选择一个地点进行评估。
- 展示公共交通连通性总分。
- 展示对应的文字等级。
- 展示评估范围内是否有站点。

### 13.2 附近站点

- 展示近距离范围内的站点列表。
- 站点信息包括站名、交通模式或线路、距离和步行提示。
- 没有站点时显示空结果提示。

### 13.3 站点地图

- 在地图中展示评估地点和周边站点。
- 展示指定范围内的站点数量。
- 从站点地图进入主地图查看。
- 列表与地图共同支持定位目标站点。

## 14. 房产实勘

房产实勘用于记录候选房产的现场观察，并把房产与选址风险信息放在一起比较。

### 14.1 新增与编辑房产

- 填写房产名称。
- 填写价格。
- 填写房产综合评分。
- 记录是否有水灾历史。
- 从已收藏地点中选择位置。
- 进入地图选择房产位置。
- 编辑已有房产记录。

### 14.2 季风检查

每个检查项使用五级星级评分：

- 排水（Drainage）。
- 防水（Waterproofing）。
- 湿度（Humidity）。
- 照明（Lighting）。

### 14.3 现场资料

- 添加实勘照片。
- 添加额外观察备注。
- 保存房产实勘记录。
- 记录房产所在地区的安全分数和附近隐患摘要。

### 14.4 房产档案

- 展示房产名称、地址、价格、评分、更新时间和风险摘要。
- 查看单个房产的完整实勘详情。
- 编辑房产。
- 将房产移入回收站。
- 选择两至三个房产进行对比。

### 14.5 房产对比

- 对比房产价格。
- 对比综合评分。
- 对比水灾历史。
- 对比安全分数和附近隐患数量。
- 对比各项季风检查评分。

### 14.6 回收站

- 查看已移入回收站的房产。
- 恢复房产。
- 清空回收站。

## 15. 隐患上报与管理

### 15.1 新建隐患报告

- 在地图位置上创建报告。
- 选择隐患类型。
- 已明确展示的类型包括洪水、犯罪、交通和基础设施。
- 填写标题。
- 填写详细描述。
- 提交隐患报告。

### 15.2 地图隐患

- 在地图上显示隐患标记。
- 显示或隐藏隐患图层。
- 查看单个隐患的详情。
- 对隐患进行反馈或投票。

### 15.3 我的隐患报告

- 展示当前用户提交的报告。
- 报告内容包括类型、标题、描述、时间和投票数量。
- 从报告定位回地图。
- 删除本人提交的报告。
- 手动刷新报告列表。

## 16. 账户中心

### 16.1 用户信息

- 展示当前用户邮箱。
- 展示用户头像占位图。
- 展示账户验证状态。

### 16.2 个人内容入口

- 房产实勘档案。
- 我的隐患报告。
- 搬迁评估历史。

### 16.3 地点与对比

- 设置或启用默认地点。
- 展示已保存的地点对比。
- 每条对比显示两地名称和评估日期。
- 查看某次保存的对比。

### 16.4 个人统计

- 展示“我的评论”数量。
- 展示“已点赞地区”数量。

### 16.5 账户操作

- 退出登录。

## 17. 核心业务对象

以下对象描述的是重新开发时需要保留的产品概念，不限定具体存储或代码实现。

### 17.1 地点

- 地点名称。
- 地理位置。
- 可作为单点分析地点、原地址、新地址、默认地点或房产位置。

### 17.2 收藏地点

- 地点信息。
- 用户自定义名称或显示名称。
- 收藏时间。

### 17.3 地点对比

- 原地址。
- 新地址。
- 评估日期。
- 可关联多个地区分析结果。

### 17.4 预算预案

- 预案名称。
- 当前月支出预算。
- 原地址与新地址。
- 两地预算换算结果。

### 17.5 隐患报告

- 隐患类型。
- 标题。
- 描述。
- 地理位置。
- 上报时间。
- 上报用户。
- 用户反馈或投票数量。

### 17.6 房产实勘

- 房产名称。
- 价格。
- 地点。
- 综合评分。
- 水灾历史。
- 排水、防水、湿度和照明星级。
- 照片。
- 备注。
- 安全与附近隐患摘要。
- 更新时间。
- 是否位于回收站。

## 18. 不纳入本次重开发基线的内容

除非后续由产品负责人明确补充，以下内容不作为当前功能知识库的一部分：

- 各类指数、评分、归一化、预测与统计拟合的具体算法。
- MVVM、Provider、Repository、缓存、同步机制等系统架构。
- 数据库表、字段、RPC、鉴权策略和外部 API 的技术接入方式。
- 独立的气候与水灾页面、七天天气、水位监控、实时洪水预警和历史降雨图。
- Magic Link、游客模式和忘记密码页面。
- 离线地图、GPS 当前定位、路线规划和公共交通班次查询。
- 旧设计文档中出现、但当前截图没有对应产品形态的其他规划功能。
