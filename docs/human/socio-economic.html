read_socio_inputs: Stable public read object (B only)

Exact object: Security-invoker View/RPC of Schema Catalog read_socio_inputs（proposed). Flutter does not directly read the five mirror tables, nor does it read hies_district、hies_state, national percentile or other decommissioned object.

Read object/exact field Access and Permissions B's usage boundaries
hh_income_district(state, district, date, income_mean, income_median)；hh_income_state(state, date, income_mean, income_median) read_socio_inputs Read-only with caller permissions; readable only by authenticated opened main application income_median It is nominal RM/month; priority is given to district by indicator, if there is a missing match, state reference
hh_inequality_district(state, district, date, gini)；hh_inequality_state(state, date, gini) Same as above gini As is 0–1; year-on-year only compares DOSM years of the same actual level, data set, and immediately adjacent to each other

read_socio_inputs A successful or partial read must bring back the above fields, data set, original date, data integrity, and imported batches; partial is never equal to zero or complete. B does not write to the database; the client has no service-role. public read permission/source/version failure passed SOCIO-001 The typed outcome returned cannot be disguised as unrecorded.

Deterministic application of rules. For each item, the latest complete DOSM date that can be shared by the current single point is given priority; if there is no common date, each item is used for the latest complete date of its own level/data set/required fields, and the years are different.missingYear is to allow levels without dates,missingLevel is Geo parsed and allows no records at all levels,missingData Yes the target level/date exists but the required fields are empty or unreadable,unresolvedGeography is the required level unresolved/ambiguous. Structural requirements: same state, same date, all mean(P1…P100) and maximum(P40/P80);Curve/position requirements all median(P1…P100). The absence of any required point is partial, and no affected structures, curves or locations are derived. Adjacent true median Linear interpolation between points only applies to income positions; below P1 and above P100 respectively represent borderline states. Amounts are always stated as "nominal RM/month, not adjusted for inflation"; official statistics are shown grouped with state-level reference/derived estimates.

5. Recommended implementation sequence

  1. B first submit declaration-only at the only entrance SocioEconomic, expose the request/results/failure/readings model; let the shell compile and test its combined behavior with fake.
  2. right LOCATION-001/GEO-001/COST-002 Create fake: cover single/A-B, resolved/ambiguous, current/no-current/number change; first prove the input and failure boundaries, and then connect to the real provider.
  3. catch read_socio_inputs, verify the keys, fields, units, statistical dates, P1–P100 integrity, security-invoker permissions and import evidence of five canonical data sets; retain typed unavailable when the data or permissions are not ready, rather than fixture.
  4. Implement each independent layer fallback, year, partial and provenance; finally form a single point/A-B to present the contribution and income position.
  5. Use a real Adapter to prove that it satisfies SOCIO-001; Shell maintains the fake consumer behavior test, and both parties only add necessary cross-module tests in Section 6.
