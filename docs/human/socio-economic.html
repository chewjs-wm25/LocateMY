应用导航与组合（SHELL-001）

提供者：Application Shell；消费者：B；唯一公开 import：package:locatemy/app/application_shell.dart

SHELL-001 的完整 canonical 声明、输入约束、结果、权限、顺序与 fake 规则只由 Application Shell 拥有。B 直接 import 该入口，绝不复制、缩窄或另造 Shell 类型。实际调用子集为同一 ApplicationShell 的 submit(ShellIntent) 与 publish(ShellContribution)，以及 canonical ShellIntentAccepted、ShellAuthenticationRequired、ShellIntentRejected(ShellRejectionReason)；ShellContributionAccepted、ShellContributionAuthenticationRequired、ShellContributionRejected(ShellRejectionReason)。ShellRejectionReason 仍为 missingInput、staleInput、inapplicableDestination、scopeUnavailable。

B 在自己的唯一入口完整声明 OpenSocioEconomicIntent、OpenSocioEconomicComparisonIntent 与 SocioEconomicContribution：意图带 immutable single 或原序 A/B 引用及返回语境；贡献带地点、层级、年份、单位、来源、状态和可比性。只有当前同账户 opened 可提交或发布；respective accepted 才导航/组合；任一 authentication-required 保持原页或保留结果不发布；rejected 不得改写成资料 unavailable。Shell 仅更新导航/组合，不能改变地点、Geo、预案或 Socio 结论；scope 关闭即丢弃待提交意图和晚到贡献。

fake 场景：accepted、authenticationRequired、staleInput；保留原地点和返回语境，拒绝不显示为“暂无社会经济资料”，过期贡献不覆盖新地点。

合法地点与行政地理（LOCATION-001、GEO-001）

提供者：Map / Location、Geographic Context；唯一公开 import：package:locatemy/features/map_location/map_location.dart；package:locatemy/modules/geographic_context/geographic_context.dart

LOCATION-001 的完整 canonical 声明只由 Map / Location 拥有，GEO-001 的完整 canonical 声明只由 Geographic Context 拥有。B 不复制或重塑任一类型；实际调用子集为 LocationCoordinator.read(LocationRole)、GeographicContext.resolve(GeographicContextRequest)，使用 frozen LocationRole（single、locationA、locationB）、LocationPresent/LocationAbsent、ValidLocationReference、GeographicLevel（district、reportingState）以及 Geo 的 canonical available/unavailable/resolved/unresolved/ambiguous outcome、failure、provenance 与 candidates。

只接受 LocationPresent：单点用 single，比较用不同且原序的 locationA/locationB。absent、非法、范围外或同点不读取 Socio、不写缓存。每端以原引用请求 district 与 reportingState；只有 GeographicLevelResolved 可进入所需层级资料读取；unresolved/ambiguous 保留 canonical reason、provenance 或完整 candidates。州 resolved 不代表行政区 resolved；按指标所需层级读取，绝不按名称、附近或默认地区猜测。调用只读；地点或边界版本变化使晚到结果失效。

if (locations.read(LocationRole.single) case LocationPresent(:final location)) {
  final geo = await geographicContext.resolve(GeographicContextRequest(

}

以上是 SOCIO-001 的完整公开声明：空字段只允许对应 unavailable/partial 的缺失事实，sourceDate 是 DOSM 原始统计日期，金额的 unit 为名义 RM/月，SocioReadingValue.displayValue 必须是可访问的原值、边界状态或文字摘要，不能以 0 代替缺失。每项读数保留 availability、availabilityReason、statisticalLevel、sourceDate、unit、sourceDataset 和 provenance；difference 只属于对应读数，且仅两端均 available、层级、年份、单位、资料集/来源、定义和完整性相同才非 null。收入位置另保留 scenarioVersion，绝不作为地点赢家或总体差异。

B 直接使用的数据与确定性规则

read_socio_inputs：稳定公共读取对象（仅 B）

精确对象：Schema Catalog 的 security-invoker View/RPC read_socio_inputs（proposed）。Flutter 不直接读取五个镜像表，也不读取 hies_district、hies_state、全国 percentile 或其他退役对象。

读取对象 / 精确字段访问与权限B 的使用边界
hh_income_district(state, district, date, income_mean, income_median)；hh_income_state(state, date, income_mean, income_median)调用者权限只读；仅 authenticated opened 主应用income_median 为名义 RM/月；逐指标 district 优先，缺匹配才 state reference
hh_inequality_district(state, district, date, gini)；hh_inequality_state(state, date, gini)同上gini 原样 0–1；同比只比较同一实际层级、资料集、紧邻 DOSM 年份
hies_state_percentile(date, state, percentile, variable, income)同上同 state/date 的 P1–P100；mean + maximum(P40/P80) 生成 B40/M40/T20，median 生成曲线和收入位置

read_socio_inputs 的成功或部分读取向本 Feature 回带字段、资料集、原始 date、完整性和导入批次；partial 不是零或完整。B 不写数据库，客户端无 service-role；permission/source/version failure 通过 SOCIO-001 的 typed outcome 返回，不能伪装无记录。

确定性规则。每项优先当前单点可共享的最新完整 DOSM 日期；无共同日期则各取本层级/资料集/必需字段完整的最新日期并显示年份不同。missingYear 是允许层级无日期；missingLevel 是 Geo 已解析而允许层级均无记录；missingData 是目标层级/日期存在但必需字段空或不可读；unresolvedGeography 是所需层级 unresolved/ambiguous。结构需同州同 date 全部 mean(P1…P100) 和 maximum(P40/P80)；曲线/位置需全部 median(P1…P100)。任一点缺失即 partial，不推导受影响结构、曲线或位置。仅收入位置可在相邻真实 median 点线性插值；低于 P1、高于 P100 显示边界状态。金额持续标注“名义 RM/月、未按通胀调整”；官方统计与州级参考/推导估算分组显示。
