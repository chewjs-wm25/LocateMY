状态：Ready for Development　Owner：A　系统基线：5d11769

唯一主应用协调 seam：在同账户已打开范围内执行首页/地图双 Tab、业务导航、返回语境和声明式组合；不拥有认证、地点、领域结果、缓存、队列或 Feature 业务写入。

定义完成：AUTH-001 确认当前设备会话且 PRIVACY-001.open 对同一不可变账户返回 opened 后才建立私有主应用。全部消费者只调用本页冻结的 SHELL-001 声明。

2. Shell 必须调用的 Interface

AUTH-001

按Authentication & Session 契约的唯一入口恢复/结束会话，不从缓存、profile 或旧 snapshot 推断认证。仅明确 authenticated 的不可变账户可继续；无会话、需验证或不可确认时保持认证/恢复态。

PRIVACY-001

Shell 是 open/close 唯一发起者；open 使用 Auth 的同一账户，只有 opened 建私有路由。退出、失效或换号时先隐藏旧 UI、拒绝意图、丢弃旧响应，再结束会话并关闭旧 scope；全部完成才登录。失败留在无私有内容的可重试恢复态；语言和公共缓存不属于 close payload。

3. Shell 必须提供的 Interface

SHELL-001 — Application Coordination

提供者：Application Shell（A）；消费者：Home、Map、Cost、Crime、Nearby Facilities、Transit、Hazard、Socio、Infrastructure、Property、Account、Suitability。

唯一公开 import：package:locatemy/app/application_shell.dart

下列声明是唯一规范。消费者可只调用需要的 submit 或 publish，不得以 ShellPublishOutcome、本地 ShellContributionOutcome 或其他变体替换成员或类型。

abstract interface class ApplicationShell {
  Future<ShellIntentOutcome> submit(ShellIntent intent);
  Future<ShellContributionOutcome> publish(ShellContribution contribution);
}
abstract interface class ShellIntent {}
abstract interface class ShellContribution {}

sealed class ShellIntentOutcome {}
final class ShellIntentAccepted extends ShellIntentOutcome {}
final class ShellAuthenticationRequired extends ShellIntentOutcome {}
final class ShellIntentRejected extends ShellIntentOutcome {
  const ShellIntentRejected(this.reason);
  final ShellRejectionReason reason;
}
sealed class ShellContributionOutcome {}
final class ShellContributionAccepted extends ShellContributionOutcome {}
final class ShellContributionAuthenticationRequired extends ShellContributionOutcome {}
final class ShellContributionRejected extends ShellContributionOutcome {
  const ShellContributionRejected(this.reason);
  final ShellRejectionReason reason;
}
enum ShellRejectionReason {
  missingInput, staleInput, inapplicableDestination, scopeUnavailable,
}

ShellIntent/ShellContribution 是 Feature 的公开 marker 基类，concrete marker 只从相应 Feature 入口导出。它必须精确声明目的地、适用时 immutable single 或原序 A/B 地点、stable ID、返回语境、scope；贡献还保留地点/角色、来源、日期、单位/口径、缓存/估算和可用性。不得携带可变地图、账户资料、原始数据库行、SDK 或其他 Feature 私有 payload。

成员输入约束typed 结果与处理副作用
submit(intent)非空；目的地唯一；ID、地点、返回语境属当前 opened scope、完整且未过期。Home/账户任务可无地点。accepted 转场；authentication required 保持当前状态并登录/恢复；rejected(reason) 保持原状态并恢复。拒绝不是领域失败。仅改门控、Tab、导航/返回栈；不写数据、改地点或领域结论。
publish(contribution)非空；绑定当前 scope 与当前请求/地点/角色/返回；保留来源、日期、口径、缓存与 available/empty/partial/unavailable。accepted 组合/渐进呈现；authentication required 不发布；rejected(reason) 不覆盖槽位并保留重试。拒绝不是领域 unavailable。仅改组合槽位；不读内部存储、置零、判定可比性或写业务。

认证页是唯一无需 opened scope 的 Shell 呈现。关闭开始后旧输入和晚到响应丢弃，新账户不继承旧 Tab、栈、ViewModel、返回或组合。分析/A-B 只使用调用时快照地点；空、未知、partial、unavailable 和零不可互换；图层点击只能产生 typed intent。

消费者可调用成员
Homesubmit：ExploreMapIntent 只切地图，不生成默认地点。
Cost、Crime、Account Centersubmit：分析/账户/房产目的地与返回语境。
Map、Nearby Facilities、Transit、Hazard、Socio、Infrastructure、Property、Suitabilitysubmit、publish：导航/返回及带提供方元数据的详情、A/B、摘要贡献。

最小调用

final ShellIntentOutcome outcome = await applicationShell.submit(
  OpenCostIntent(location: location, returnContext: returnContext),
);
// 仅 ShellIntentAccepted 才转场。

fake Adapter：以同一 Interface 分别回 accepted、authentication-required、staleInput rejected，验证只有 accepted 导航/组合；其余保留 immutable 输入、草稿或结果及文字恢复。旧地点/账户贡献不覆盖槽位，也不造成写入、上传或伪装的领域失败。

5. 推荐实施顺序

  1. 接入 Auth/Privacy 唯一入口，先合入本声明。
  2. 实现 same-account opened 门控和关闭 barrier。
  3. 完成双 Tab、返回、账户任务和语言，不碰 Feature 数据。
  4. 以固定 submit/publish 接入 marker；消费者先用 fake。
  5. 验证真实 Adapter；Widget、状态管理、SDK、并发、取消、重试和测试组织归 Owner。
